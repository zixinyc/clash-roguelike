# 05 · 界面面板

界面图最容易出问题的地方是：（AI 爱偷偷加文字、爱加按钮、爱把面板画成现代扁平风）。所以这一类模板的"禁止"写得特别长，这不是啰嗦，是必要。

## 先搞清楚一件事：本项目的界面是「程序画的」还是「出一张图」？

《余烬交锋》现在的界面是 Godot 里用代码画的（`battle-demo/scripts/map_visuals.gd` 里有统一的色板和控件样式），（不是）贴图。

所以这个文件里的模板，用途是：

1. （补齐代码画不出来的部分）：复杂花纹、装饰边框、插画式面板、卷轴羊皮纸、图标装饰件
2. （给换皮/做宣传图/做商店页时快速出一版效果图）
3. （给游戏内嵌的小插图）（探险手记封面、结算画面、章节过场图）

（不要）用这一类图去替换现有的程序化控件样式，那会破坏统一色板和测试护栏。

## 模板 5-A：弹窗面板（白底合成图）

（怎么填）：改【面板用途】和【分区】。

```text
请生成一张【游戏弹窗面板】。

【面板用途】 【例如：战后三选一奖励弹窗】。
【整体尺寸】竖版 3:4（如 1536×2048）。
【结构分区】（从上到下）
1. 顶部标题区：高 【14】】，（留空）。
2. 内容区：高 【66】】，分 【3】 个等宽的并列小格，每格（留空）（后期要贴卡牌或图标）。
3. 底部按钮区：高 【20】】，有 【3】 个并排的圆角按钮，（按钮上留空），不要写字。

【材质做法】羊皮纸 #f6edd8 纸面，边缘微微卷起和做旧；外框是深木 #241b13 + 黄铜金 #d6a447 双层细边；四角有小小的卷叶或铆钉装饰。
【画风】2D 手绘厚涂 + 绘本感，笔触干净，带一点点厚度和立体倒角。
【光线】左上 45 度暖色斜射光，纸面有轻微起伏阴影。
【背景】纯白 #FFFFFF 平铺，不要投影、不要倒影、不要桌面。
【禁止】任何文字、字母、数字、符号、logo、水印；不要在留空区画花纹；不要现代扁平 UI 风格、不要圆角卡片风、不要玻璃拟态；不要按钮图标；不要渐变紫蓝。
【画幅】1536×2048。
```

## 出完后的检查

1. 留白区真的空吗？（这是这一类图最容易翻车的地方）
2. 有没有偷偷出现的文字、字母？
3. 是不是画成了现代扁平 UI？→ 那就完全不能用，重出
4. 配色有没有跑出色板？
5. 背景纯白吗？有没有自带投影？
6. 和游戏里现有的界面风格（暖色木框 + 羊皮纸 + 黄铜金）像吗？

## 实测校准（ref_06 与 ref_07 已验证）

成品提示词原文见《参考图与实测记录.md》7-6 与 7-7 节。

1. （留空指令有效）。实测卡牌框五个分区全空、无花纹无文字；手记面板两个内容区全空。
2. （但会自带边缘投影）。手记面板右下有一道浅投影，提示词写了「不要投影」也没用。抠底前先删投影，或者把投影当成卡片自身的一部分保留。
3. （本项目界面是代码画的）。这批图只用于补代码画不出来的花纹和装饰件，不要拿去替换 `map_visuals.gd` 的控件样式。
