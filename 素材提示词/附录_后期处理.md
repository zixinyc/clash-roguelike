# 附录 · 后期处理

出图只是第一步。这一步把 AI 出的图变成（能直接进游戏的素材）。

这一部分的做法来自参考视频的最后一节：（让 AI 帮你写小工具），比手点软件快，也比一次次的提示词稳。

---

## 一、去底（抠背景）

### 1-A：纯色背景去底（让 AI 写个工具）

（怎么用）：整段贴给 AI，让它写成一个能直接在电脑上跑的小脚本。

```text
请写一个 Python 脚本，用 Pillow（PIL）库把图片的纯色背景去掉，导出带透明通道的 PNG。

【输入参数】
- 输入图片目录：./in
- 输出图片目录：./out
- 背景颜色阈值容差：32（0-255）

【处理规则】
1. 遍历 ./in 下所有 .png 和 .jpg。
2. 对每个像素，计算它与背景色的距离。距离小于容差的，判定为背景，alpha 设为 0。
3. 透明区域在输出时使用「边缘颜色外扩」：把不透明像素的颜色向透明区域扩散 1 像素，消除抠完底之后的一圈白边或绿边。
4. 对半透明边缘像素，按距离做平滑过渡，避免边缘出现硬锯齿。
5. 输出文件名和输入文件同名，扩展名统一为 .png，保存在 ./out。

【额外输出】
- 处理完打印每张图的处理结果：文件名、原始尺寸、输出尺寸、去掉了多少比例的像素。
- 如果某张图去底后剩余前景像素少于 2%，在最后汇总里单独列出来，提示这张图可能底色不对。

【要求】
- 脚本要能在 Windows 上用 python 直接跑，不要用 Linux 专有命令。
- 依赖只有 Pillow，如果没装要在开头用 try/except 提示一句。
- 每一步加中文注释。
```

### 1-B：整张图里的多个物体分离（让 AI 写个工具）

```text
请写一个 Python 脚本，用 Pillow（PIL）库把一张「4 行 4 列合集图」切成 16 张独立小图。

【输入参数】
- 输入图片：./in/sheet.png
- 输出目录：./out
- 行列：4 行 4 列（16 格）

【处理规则】
1. 计算每格宽 = 总宽 ÷ 4，每格高 = 总高 ÷ 4。
2. 逐格裁剪并保存为 sheet_00.png 到 sheet_15.png，编号按「从左到右、从上到下」。
3. 每格裁剪后，裁掉四周完全透明的像素（保留 2 像素余量）。
4. 裁完统一居中放到 512×512 的透明画布上（等比缩放，不放大超过原尺寸），另存为 *_512.png。
5. 输出前对每张图做一次「去白边」处理：边缘半透明的白色像素，把颜色替换为它内侧最近的非白色像素颜色。

【要求】
- Windows 上能直接跑，依赖只有 Pillow。
- 打印每张切出来的小图尺寸。
- 每一步加中文注释。
```

## 二、把边缘的脏色洗掉（对应视频里洗「伪像素风」那一步）

手绘厚涂风洗不出像素图，但有同一个问题要解决：（AI 出的图边缘有半透明的脏色）（俗称"糊边"）。处理办法：

```text
请写一个 Python 脚本，用 Pillow（PIL）库清洗 PNG 素材的边缘脏色。

【输入参数】
- 输入目录：./in
- 输出目录：./out
- 透明阈值：alpha 小于等于 8 视为完全透明

【处理规则】
1. 对每张 PNG：alpha 小于等于 8 的像素直接设为全透明。
2. 边缘去白边：找出 alpha 在 9 到 250 之间的半透明像素，把它们的 RGB 替换为「同一区域内最近的完全不透明像素的颜色」。
3. 颜色吸附：统计这张图里出现最多的 16 种不透明颜色，把所有像素的颜色吸附到这 16 色中最接近的一个（保留 alpha）。
4. 输出 RGBA PNG，并打印处理前后「不同颜色数量」的对比。

【要求】
- Windows 上能直接跑，依赖只有 Pillow。
- 每一步加中文注释。
```

## 三、重排格子（对应视频里 3×4 转 4×4 的那步）

```text
请写一个 Python 脚本，用 Pillow（PIL）库把一张精灵图（sprite sheet）按指定的格子顺序重新排列。

【输入参数】
- 输入图片：./in/sheet.png
- 输出图片：./out/sheet_reordered.png
- 原网格：3 列 4 行
- 新网格：4 列 4 行

【处理规则】
1. 计算原格宽 = 总宽 ÷ 3，原格高 = 总高 ÷ 4，逐格裁剪原图，共 12 格。
2. 按下面的映射关系填进新网格（从左到右、从上到下编号，新网格共 16 格）：
   - 新图第 1 列 = 原图第 2 列的 4 格
   - 新图第 2 列 = 原图第 1 列的 4 格
   - 新图第 3 列 = 原图第 2 列的 4 格
   - 新图第 4 列 = 原图第 3 列的 4 格
3. 新网格里多出来的 4 格填透明像素。
4. 每格大小一致，输出 PNG。

【要求】
- Windows 上能直接跑，依赖只有 Pillow。
- 打印原图尺寸、每格尺寸、新图尺寸。
- 每一步加中文注释。
```

## 四、把颜色拉回项目色板

出图后颜色常常和项目色板有偏差（偏蓝、偏灰、偏紫）。一次性拉回来的办法：

```text
请写一个 Python 脚本，用 Pillow（PIL）库把一批 PNG 的整体色调拉回指定的暖色色板。

【输入参数】
- 输入目录：./in
- 输出目录：./out

【目标色板（暖色系）】
- #33261a 胡桃木底
- #241b13 深木底
- #463423 木质高亮
- #8c6b3b 木质描边
- #d6a447 黄铜金
- #f5c963 暖阳金
- #f6edd8 羊皮纸
- #ebe0c5 羊皮纸浅
- #2b1e12 墨褐
- #634e38 次级墨色
- #fbf3df 奶油白
- #6bc275 翠绿
- #cf4036 猩红
- #2fa6b8 青蓝

【处理规则】
1. 对每张图，把所有不透明像素的颜色吸附到上面 14 个色板色里最接近的一个（用感知加权距离，不要用生硬的 RGB 欧氏距离，避免明暗层次被压平）。
2. 保持 alpha 通道不变。
3. 保持原图尺寸不变。
4. 处理前后各统计一次颜色数量，打印对比。

【要求】
- Windows 上能直接跑，依赖只有 Pillow。
- 每一步加中文注释。
```

## 五、等比缩放到游戏里用的尺寸

```text
请写一个 Python 脚本，用 Pillow（PIL）库批量把 PNG 缩放到指定尺寸。

【输入参数】
- 输入目录：./in
- 输出目录：./out
- 目标长边：512 像素

【处理规则】
1. 遍历输入目录下所有 PNG。
2. 等比缩放，长边缩到 512 像素（不要拉伸变形，不要放大超过原尺寸）。
3. 用 LANCZOS 插值。
4. 保留 alpha 通道，缩放后把 alpha 小于等于 8 的像素设为全透明。
5. 输出同名 PNG。
6. 打印每张图缩放前后的尺寸。

【要求】
- Windows 上能直接跑，依赖只有 Pillow。
- 每一步加中文注释。
```

## 六、手工检查清单

工具跑完之后，这几样还是要用眼睛看一遍：

- [ ] 边缘有没有残留一圈白边 / 绿边 / 黑边？
- [ ] 半透明的头发、衣角、烟雾有没有被误删？
- [ ] 吸附色板之后，暗部是不是糊成一片？（糊了就少吸附几个颜色）
- [ ] 切出来的 16 格，格子顺序和分解表对得上吗？
- [ ] 每格里的主体位置一致吗？（不一致就统一缩放 + 居中）
- [ ] 缩放之后，48×48 缩略图还认得出吗？
- [ ] 命名和放的位置对吗？（对照《README》的命名表）
- [ ] 在 `asset/素材清单.md` 里登记了吗？

## 七、AI 出图工具的坑，记一下

1. （一定要带参考图。） 不带，每张图画风都会飘，这是整套流程的地基。
2. （AI 画的字一定不能用。） 标题、描述、费用数字，全部后期贴。
3. （AI 很爱加投影和倒影。） 每条提示词都要重复写「不要投影、不要倒影」。
4. （AI 会自作主张改画幅。） 尺寸一定要写死。
5. （超过 10 帧排不齐。） 长动作拆成两段出。
6. （格子里的主体大小不一致。） 出图后统一缩放居中，别指望 AI 对齐。
7. （一次别要太多。） 一张图一个东西，一次发一批容易跑偏。
8. （出图不满意就重出，不要硬修。） 修一张的功夫，重出三张还差不多。
