# 03 · 场景与地图

这个文件做三件事：战斗背景、探索楼层地图、场景里能抠出来单独用的物件。

## 先想清楚一件事：你要的是「整张背景」还是「能拼的零件」

| 你要的东西 | 出图方式 | 后续处理 |
| --- | --- | --- |
| 战斗背景（战斗舞台底图） | 一整张 1920×1080，带纵深、不带角色 | 直接用，不用抠 |
| 探索楼层地图（路线图底图） | 一整张俯视图，只画地形纹理，不画节点图标 | 节点图标另外单独出 |
| 场景物件（桌子、树桩、箱子） | 白底合集图，再切 | 切图后单独用 |

（别混）：一张图里同时塞背景和零件，最后两边都难用。

## 模板 3-A：战斗场景背景

（怎么填）：改【场景名称】【时间】【氛围层】【前景遮挡物】。

```text
请生成一张【游戏战斗场景背景】。

【场景】 【场景名称，例如：废林深处的废弃伐木营地】。
时间与光线： 【正午林间 / 清晨薄雾 / 黄昏斜阳 / 雨后】，太阳在画面【左上方 / 右上方】，斜射光穿过【树冠 / 破损屋顶 / 云层】，光柱和浮尘可见。
氛围层： 【从四层氛围里选一个：晨雾翠林（青绿湿润、晨雾、斑驳光斑）/ 金秋枫径（橙红枫叶、斜阳、暖金主调）/ 暮光古原（暗红琥珀、低角度余晖、长影）/ 烬心巨像（焦黑岩层、熔金裂隙、灰烬飘落）】。

【画风】2D 手绘厚涂，绘本感，笔触干净，边缘清晰，不要 3D 渲染感。
【配色】整体压在这套色板里：胡桃木 #33261a、深木 #241b13、黄铜金 #d6a447、暖阳金 #f5c963、羊皮纸 #f6edd8、奶油白 #fbf3df、墨褐 #2b1e12；暗部一律偏暖褐，不要灰黑。
【构图】横版 16:9。地面压在下 1/3，中间留出开阔的活动区域（战斗时角色站在这里），背景纵深分三层：前景剪影 / 中景主体 / 远景雾化。
【前景遮挡物】 【画面下缘和左右边缘各压一点暗部剪影，例如倒伏的树干和垂下的藤蔓】，用来增加层次，但不要遮挡中间区域。
【禁止】任何角色、人物剪影、敌人、怪物、文字、字母、数字、logo、水印、按钮、UI 元素、边框；不要冷蓝灰、霓虹、紫色天空。
【画幅】1920×1080。
```

（注意）：背景图不要留太干净。三层纵深 + 前景遮挡物，是让战斗画面不"平"的关键。

## 模板 3-B：探索楼层地图底图

（用途）：给废林方格地图做底图。（这张图只画地形和质感，不画节点图标）——节点图标由 04 号文件单独出，这样路线逻辑改了也不用重画地图。

```text
请生成一张【游戏探索地图底图】。

【视角】正俯视（top-down，垂直向下看，无透视变形，不要斜 45 度），正方形画幅。
【地图类型】 【林地 / 遗迹 / 洞穴 / 古原】。
【地形】 【地表起伏、河流位置、岩石分布、树木密度、道路走向】。
【地貌氛围】 【从四层氛围里选一个】。

【画风】2D 手绘厚涂，绘本感，笔触干净，边缘清晰，不要 3D 渲染感。
【配色】整体压在这套色板里：胡桃木 #33261a、深木 #241b13、黄铜金 #d6a447、暖阳金 #f5c963、羊皮纸 #f6edd8、奶油白 #fbf3df、墨褐 #2b1e12；暗部一律偏暖褐。
【明暗】从左上到右下有整体的光线梯度（阳光来自左上），地形起伏用柔和投影表现，不要硬描边。
【重要】这张图只画【地形与质感】。不要画任何路径标记、节点图标、圆点、连线、箭头、旗帜、标记牌。
【禁止】任何角色、文字、字母、数字、logo、水印、按钮、UI 元素；冷蓝灰、霓虹、紫调。
【画幅】2048×2048。
```

## 模板 3-C：场景物件合集（白底，可抠）

（用途）：出完场景图后，把里面能单独用的东西再出一版白底合集，切开就能拼。

（怎么填）：改【物件清单】和【每行几个】。

```text
请生成一张【场景物件合集图】。

【物件清单】（每样东西单独一件，互不重叠，之间留出空隙）
【物件清单，例如：
1. 木桶（铁箍）
2. 破麻袋
3. 长木桌
4. 木凳
5. 熄灭的火堆
6. 长剑（插在地上）
7. 树桩
8. 石块
9. 干枯的药草
10. 卷起的羊皮纸
11. 铁烛台
12. 陶罐】

【排布】一行 4 个，共 【3】 行。每行从左到右按上面的清单顺序排。每个物件单独一格，大小控制在整格高度的 70% 以内，格与格之间留出明显空隙。
【画风】2D 手绘厚涂，绘本感，笔触干净，和战斗场景同一套光（左上 45 度暖色斜射光）。
【配色】物件主色压在这套色板里：胡桃木 #33261a、深木 #241b13、黄铜金 #d6a447、暖阳金 #f5c963、羊皮纸 #f6edd8、墨褐 #2b1e12。
【背景】纯白 #FFFFFF 平铺，画面里不许出现任何阴影、投影、倒影、地板、边框。
【禁止】任何文字、字母、数字、编号、logo、水印；不要让两件物件互相重叠；不要自带底座或地面。
【画幅】2048×1536。
```

（抠完底注意）：白底图去底后，物件的描边内侧往往有一圈白边。去底脚本里记得加一步「边缘收缩半像素」或「边缘颜色外扩」（见附录）。

## 模板 3-D：同一场景换氛围（四层通用）

（用途）：一个场景要在四层里复用时，用这条出同一场景的不同配色版本。

```text
请参考我上传的这张【场景图】，用【完全相同的地形布局、物体位置、构图、笔触、透视】，只改【配色与光线】，生成新的一张。

【新氛围】 【四层氛围之一：晨雾翠林 / 金秋枫径 / 暮光古原 / 烬心巨像】。
【改动范围】
- 整体色温改为【青绿湿润 + 冷雾 + 暖光斑 / 橙红暖金 + 斜阳 / 暗红琥珀 + 低角度余晖 / 焦黑 + 熔金裂隙】
- 天空与远景颜色随之改变
- 地面与植物颜色随之改变
- 光源位置不变（左上 45 度），只改色温和强度
【保持不变】地形轮廓、物体位置、大小比例、笔触、描边、细节、构图。
【禁止】任何文字、字母、数字、logo、水印、UI 元素；冷蓝灰、霓虹、紫调。
【画幅】1920×1080。
```

## 出完后的检查

1. 背景里有没有混进人物？→ 重出（这类图最常见的问题）
2. 地图底图里有没有节点图标、连线？→ 重出
3. 物件图里物件有没有重叠？→ 重出
4. 同一场景的换色版本，地形位置和原图对得上吗？
5. 画面整体是不是冷蓝灰？→ 重出或后期拉色
