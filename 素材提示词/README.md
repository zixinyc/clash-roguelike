## 二、风格锁（每条提示词都要带这一段）

### 2.1 画风

- 2D 手绘厚涂 + 绘本感，笔触干净，边缘清晰，不要糊、不要涂抹感、不要 3D 渲染感
- 光线：左上方 45 度暖色斜射光；受光面暖亮，暗部偏暖褐（不是灰黑），投影短且柔
- 描边：要描边就用深墨褐 `#2b1e12`，线宽统一；不要纯黑描边
- 构图：主体居中，四周留 8% 空白，不裁切、不贴边

### 2.2 固定色板（写进提示词；出图后有偏差就用取色器拉回来）

| 用途 | 色值 |
| --- | --- |
| 胡桃木底（面板主色） | `#33261a` |
| 深木底（凹陷区、外边框） | `#241b13` |
| 木质高亮（悬停态） | `#463423` |
| 木质描边 | `#8c6b3b` |
| 黄铜金（主边框、强调） | `#d6a447` |
| 暖阳金（高光、阳光、焦点） | `#f5c963` |
| 羊皮纸（内容区） | `#f6edd8` |
| 羊皮纸浅（分区底） | `#ebe0c5` |
| 墨褐（描边、正文） | `#2b1e12` |
| 次级墨色（弱化说明） | `#634e38` |
| 奶油白（主要文字） | `#fbf3df` |
| 翠绿（生命、增益） | `#6bc275` |
| 猩红（警示、受伤） | `#cf4036` |
| 青蓝（情报、水系） | `#2fa6b8`

主色只从这套里取。角色主色可以比色板饱和度高半档，其余部分一律压成暗部。

### 2.3 四层场景氛围（换层就换这一行）

| 层 | 氛围描述 |
| --- | --- |
| 晨雾翠林 | 青绿湿润，晨雾弥漫，斑驳光斑，冷绿与暖光对比 |
| 金秋枫径 | 橙红枫叶，斜阳穿林，暖金主调 |
| 暮光古原 | 暗红琥珀，低角度余晖，影子拉得很长 |
| 烬心巨像 | 焦黑岩层，熔金裂隙，灰烬飘落，压迫感强 |

### 2.4 禁用清单（负面提示词）

冷蓝灰配色、霓虹赛博、纯黑描边、3D 写实渲染、Q 版大头、日式动漫大眼萌系、蓝紫主色调、廉价金属高光、文字、字母、数字、logo、水印、边框、UI 元素、现成 IP 角色、人物照片写实脸。

## 三、通用硬规则（每条提示词都要带）

1. （不要任何文字）。字、标签、数字一律后期自己贴，AI 画的字必然是错的。
2. （背景写死）。要抠底的素材写「纯绿幕 `#00FF00` 纯色，画面里不许出现任何绿色元素」；不用抠的写「纯白底」。
3. （不要投影、不要倒影、不要地面反射）。AI 很爱加地面倒影，会挡住后面拼图。
4. （不要光晕溢出边缘）。
5. （网格排布写死）：几列乘几行、每格放什么、从左到右还是从下到上，全部写出来。
6. （画幅写死）（如 1024×1024、2048×1024、1920×1080），否则 AI 自作主张改比例。
7. （一张图只出一个东西）。不要一张图里同时塞角色、背景、UI。
8. （四周留白 8%），主体完整不裁切。

## 五、一次完整流程（照着走）

（第 1 步 · 出风格基准图）
用 01 号文件的「模板 1-A」，选一个你最有把握的角色出 1 张。满意之后，这张图就是全项目的画风基准。

（第 2 步 · 带着基准图批量出图）
打开 AI 的图片上传功能，（每次都把这张基准图一起发上去），然后贴对应类型的模板。这是整套流程里最关键的一步，跳过它，每张图的画风都会飘。

（第 3 步 · 后期处理）
切图、去底、对齐格子、拉回色板：看《附录_后期处理.md》，里面连「让 AI 帮你写切图工具」的提示词都写好了。

（第 4 步 · 落盘 + 登记）
按《六、命名与落盘》改名放进 `asset/`，然后在 `asset/素材清单.md` 里登记：怎么生成的、提示词是什么、哪张是参考。

## 六、命名与落盘

| 类型 | 放哪 | 命名规则 | 例子 |
| --- | --- | --- | --- |
| 角色立绘 | `asset/char/` | `char_<角色id>_<动作>_<状态>.png` | `char_ash_idle_calm.png` |
| 动作帧 | `asset/char/anim/` | `anim_<角色id>_<动作>_<帧数>f.png` | `anim_ash_attack_8f.png` |
| 敌人 | `asset/enemy/` | `enemy_<名称>_<动作>.png` | `enemy_sentinel_elite.png` |
| 图标 | `asset/icon/` | `icon_<类别>_<名字>_00.png` | `icon_relic_rune_feather.png` |
| 卡牌 | `asset/card/` | `card_<卡key>_frame.png` / `card_<卡key>_art.png` | `card_ember_frame.png` |
| 场景背景 | `asset/bg/` | `bg_<场景>_<层>.png` | `bg_forest_ruin_mist.png` |
| 探索地图 | `asset/map/` | `map_<楼层>.png` | `map_forest_f1.png` |
| 物件 | `asset/prop/` | `prop_<名字>_00.png` | `prop_barrel_00.png` |
| 特效 | `asset/fx/` | `fx_<类型>_00.png`（沿用现有规格 512×512） | `fx_ember_burst_00.png` |
| 界面 | `asset/ui/` | `ui_<用途>.png` | `ui_handbook_panel.png` |

规矩：

- 透明素材一律 PNG、带 Alpha 通道
- 一张图里不要塞多个版本（不要三选一摆一张图上）
- 每个文件都要在 `asset/素材清单.md` 里登记来源：生成方式、模型、日期、提示词、参考图是哪张
- 新增文件夹记得放一个空的 `.gdignore`（和 `asset/参考源码/` 一样的做法），免得 Godot 去导入不该导入的东西

## 七、出图自检清单

出完一张，对一遍下面的条目，有一条不过就重出或者后期修：

- [ ] 画面里有没有多出文字、字母、数字？有 → 让 AI 重出
- [ ] 主体有没有被裁切、贴边？
- [ ] 背景是不是干净的纯色？中间有没有混进别的东西？
- [ ] 有没有投影、倒影、地面反射？
- [ ] 颜色有没有跑成冷蓝灰、霓虹、紫调？
- [ ] 描边是不是纯黑？
- [ ] 每一格的内容，跟分解表对得上吗？顺序对吗？
- [ ] 尺寸跟要求一致吗？
- [ ] 抠完底之后边缘有没有白边、黑边、绿边？
- [ ] 是不是忘了把基准图一起发上去？

## 八、实测校准

2026-11-23 在本机 ComfyUI 真跑了 7 张参考图（Qwen-Image-2.1 Turbo + Qwen3VL 8B，20～41 秒一张）。

参考图在 `参考图/`，逐张评价、8 条硬事实、踩过的坑、成品提示词原文，全在《参考图与实测记录.md》。下面是最需要改的三条：

1. （提示词里不要写色号）。写成「黄铜金」而不是 `#d6a447`，色号可能被模型画成画面里的文字。
2. （要抠底的素材优先用纯白底，不是绿幕）。实测「纯绿色幕布」出的是带暗角的橄榄绿（RGB 80,111,55），纯白底干净得多。
3. （否定式约束不如正面描述）。「不要日式动漫大眼」压不住，改成「西式绘本脸型、眼睛偏小、下颌柔和」才有效。

本机一键出图命令见《参考图与实测记录.md》第五节。
