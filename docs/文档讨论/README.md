## 和朋友怎么用

1. 打开对应文档，先看现有内容，避免重复。
2. 编辑时写出具体场景、想带来的选择和还不确定的地方。
3. 用任务分支提交改动并发起 PR，朋友可以在 PR 里评论。
4. 达成一致后把结论更新到玩法设计，保留讨论来源。

“提议”不等于“已确认”，更不等于“已经实现”。不要直接用未经讨论的想法覆盖确定规则。
