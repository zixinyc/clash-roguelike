# hunter｜联机猎人模式

更新日期：2026-10-26
状态：核心概念已确认，详细玩法继续讨论；尚未实现联机。

## 模式概念

一名玩家先行动若干回合，随后其他联机玩家加入追杀。先行动的玩家需要一边推进通关，一边避免被追杀致死。

这里的“先手”按用户原意记录为回合领先，不擅自改成地图层数或现实时间；具体如何计算回合尚未确定。

## 角色与已确认流程

- **被追杀者**：先开始行动、以通关为目标的玩家。
- **猎人**：后续参与追杀的联机玩家；具体人数与合作方式待定。
- **先行阶段**：被追杀者先行动若干回合。
- **追杀阶段**：后续玩家开始追杀；被追杀者继续争取通关。

## 已确认的胜负条件

以被追杀者视角记录：

| 事件 | 结果 |
| --- | --- |
| 被追杀者通关 | 被追杀者胜利 |
| 被追杀者被追杀致死 | 被追杀者失败 |

猎人是团队获胜还是只奖励完成击杀者、被追杀者死于普通敌人的处理、同时通关与死亡的优先级，都尚未确定。

## 仍需讨论

1. **追杀如何发生**：猎人在同一地图追赶并与被追杀者直接战斗，还是控制敌人、布置阻碍来干扰？
2. **领先如何计算**：先行多少回合，之后同步推进、轮流行动还是各自行动？
3. **猎人如何成长**：后加入时有什么牌组、队伍与 cost，是否也能打怪或购物？
4. **与基础战斗的关系**：是否沿用小队、手牌、拼点和 cost；玩家对战是否需要不同规则？
5. **对局边界**：人数、超时、断线、普通战斗死亡、平局与同时事件如何处理？

这些都是待定问题，不在本轮一次性决定。优先讨论第一项，让大家对“追杀”的实际操作形成共同理解。
