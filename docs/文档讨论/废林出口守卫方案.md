# 废林出口守卫方案

状态：玩法预览，待确认开发。基于现有 6×4 地图和两组敌人。

## 目标

每局废林探索以一场守卫战收尾，让途中积累的 cost 和保存下来的生命有用武之地。玩家可以少打沿途战斗，也可以根据小队状态绕去找补给、治疗或事件。

## 本轮规则

1. 目标栏显示「击败出口守卫」。探索仍按上下左右逐格移动，出口地点随迷雾揭开。
2. 从任意相邻格点击「出口守卫」，显示当前生命与 cost，并提供「挑战守卫」「返回探索」。返回时停在原格，可以继续备战。
3. 确认后带着当前小队生命与 cost 开战。首次试玩暂用缚咒祭司与鸣钟行刑者，检验探索和战斗衔接。
4. 守卫战胜利即通关，战败即结束本局。结算显示结果、剩余生命和 cost，玩家可重新探索。

沿途节点沿用现有内容。开发范围为出口交互、守卫战接入及通关和战败结算。行动点、专属 Boss 技能和地图重新布局待另行讨论。

## 两条试玩路线

地图坐标从左上角 `(0,0)` 起算。预览为方便讨论，展示了完整地图。

- 直行五步，从 `(0,1)` 出发，先打 `(2,1)` 普通敌组，再经过 `(4,1)` 营地，到达 `(5,1)` 守卫处。适合验证战斗损耗、营地决策和跨场资源继承。
- 北侧绕行七步，从 `(0,1)` 经 `(0,0)`、`(1,0)` 补给、`(2,0)`、`(3,0)` 事件、`(3,1)`、`(4,1)` 营地抵达守卫。适合验证沿途零战斗也能备战并抵达终点。

## 开发与验收

1. 接入出口确认和战斗结果，更新地图操作说明。
2. 验证所有入口都需击败守卫才能通关；取消挑战后位置、生命和 cost 都正确，且可以再次挑战。
3. 验证带伤与低余额进入守卫战时继承资源，通关和战败均正确结算，重开可再次挑战。
4. 跑现有地图与战斗回归，再按上述两条路线试玩，记录到达出口时的生命和 cost，观察守卫是否让营地和补给成为有意义的选择。
