# 暗黑奇幻角色与敌人概念草案

状态：概念预览，尚未接入游戏。目标：为拼点战斗提供风格一致、打法各异的小队和敌人。以三名角色及三种普通敌人、一名精英为首轮范围，数量可根据试玩调整。

## 世界与小队
灰灯会是一支探索被诅咒遗迹的小队。成员有共同的灰黑披风和琥珀灯徽，依靠武器和轮廓区分。敌人来自钟声诅咒笼罩的废弃圣堂。

- 灰烬，蓄势者：窄剑与提灯，观察后抓准时机，在关键拼点释放准备。
- 长锋，破阵者：重甲与巨剑，以高投入换取更强拼点，失败承受代价。
- 织火，援护者：法杖与圆盾，为队友提供防护并协助应对关键攻击。

## 敌人
- 裂影斥候：轻甲双钩、速度快，攻击威力低但擅长干扰准备；教玩家识别需要优先处理的行动。候选效果：命中时移除目标一层准备，实际适配待定。
- 守墓盾卫：重盾和宽厚盔甲，蓄力后发动高威力攻击；考验蓄势和接招时机。候选效果：防御回合获得护盾，随后进行重击。
- 缚咒祭司：兜帽、法印和法杖；给队友提供增益，促使玩家在正面接招和优先击破支援者之间取舍。
- 精英：鸣钟行刑者，巨大破钟与锁链锤；交替使用可辨认的蓄力与重击，在高压回合考验队伍分配，避免将瞬杀当作主要难度。
