> **魔理沙特殊被动：生命借费 (Blood Theft)**
> 当我方剩余 cost 不足支付魔理沙的行动，且魔理沙生命大于差额的 5 倍、敌方有尚未预留的 cost 时，魔理沙可按 **5 HP : 1 敌方 Cost** 的比例偷取敌方费用完成规划。取消行动不扣血，只有回合锁定结算时才正式扣减生命与敌方费用。

## 三、 战前技能组与卡组预设方案 (Deck Loadouts)

在 `touhou` 分支中，战前准备页与技能预设采用 **A / B 方案**：
1. **方案 A（完整专属构筑）**：默认携带该角色全部可用专属技能牌与通用牌。
2. **方案 B（偏进攻突击构筑）**：自动筛选携带前 2 张有伤害的进攻牌，精简卡组以提升特定关键牌抽取与流转效率。
3. **阵容预设**：
   - **东方三人组**：雾雨魔理沙 (0号位) + 十六夜咲夜 (1号位) + 博丽灵梦 (2号位)
   - **ZiXi 独立组**：灰烬 (0号位) + ZiXi (1号位) + 织火 (2号位)
   - **应晨子星组**：灰烬 (0号位) + ZiXingYC (1号位) + 织火 (2号位)
   - **原小队**：灰烬 + 长锋 + 织火
