# 行动规划与速度

更新：2026-10-29。本文覆盖旧草案中“逐张即时结算、每人一次行动”的演示假设。

## 已确认

- 每回合固定敌方先规划并锁定，再由玩家响应。Demo 中敌方是人机；猎人模式中是猎人。先规划不等于先结算。
- 双方速度公开，每个行动格的速度按角色特性随机生成。整个规划阶段不变，下一回合重新生成。
- 敌方行动格分进攻、大招、防御；暗表示未启用，亮表示启用。公开攻击目标箭头，隐藏卡牌、威力和硬币数，不显示拼点胜率。
- 每名队员可安排多个行动。玩家规划阶段可改牌、改目标、撤销，界面显示准备状态。
- 响应时间 180 秒，提前准备完成就结算；超时锁定已有安排，空格待机。
- 双方锁定后揭晓技能并按速度统一结算，实际拼点逐次掷币。
- 原目标可以迎击，替队友接招必须速度严格高于对应敌方行动。
- 本次暂不做地图；猎人模式的真实多人协议尚未实现。

## 当前演示参数

每人三个分类格，每格最多一张牌、每人最多两次行动。三人共享六张固定手牌和 cost 钱包，初始 12 cost，每回合 +3。该布局限制、牌数、速度区间、血量与经济数值用于试玩，不代表最终平衡。

| 角色 | 每格速度区间 | 定位 |
| --- | --- | --- |
| 灰烬 | 3–6 | 中速前锋 |
| 长锋 | 5–8 | 高速接招 |
| 织火 | 2–5 | 低速支援 |
| 锈刃巡卫 | 2–5 | 低速敌人 |
| 失序哨兵 | 4–7 | 快速敌人 |

安排阶段只预留费用；锁定一次性支付全部安排。撤销释放预留费用。拼点最终失败只返还对应卡牌实付费用的 50%，向下取整；本回合首次拼点获胜 +1 cost。锁定后角色或目标退场导致行动取消，不自动转移目标、不退费，此项仍需试玩评估。

## 接招与结算

我方攻击箭头指向敌方具体行动格。若该敌方格是启用的进攻或大招，且指向自己，形成迎击；若指向队友，必须速度更高才能接走。指向防御格或未启用格的攻击属于单方面攻击，不消耗敌人的其他攻击。

多个我方行动争抢同一个敌方格时，速度最高者接招；同速按行动格编号。其余行动单方面攻击对应敌人。单次行动最多参与一场拼点。

拼点按参与双方较高速度进入结算顺序，其余行动按自身速度。同速按固定行动编号处理。角色退场后的后续行动取消；已经失去目标的攻击取消。护盾按防御行动实际执行时生效。

## 平局试行规则

普通平局重掷，不随机破坏任何一方硬币。若剩余硬币所有可能结果必然相同，直接僵持；极端连续 100 次平局也以僵持结束以保护运行。僵持双方不造成伤害，玩家退还该牌一半费用。该保护规则是本项目试行设计，并非《废墟图书馆》原规则复刻。

## 实现与后续

规则层输出公开快照与结算事件，UI 播放事件，不影响随机结果。敌方卡牌标识在响应阶段的公开快照中被移除；本地进程仍保存完整规则状态，不能替代联机服务端保密。

下一步试玩重点：180 秒是否合适、两次行动与分类格是否过于限制、接招速度区间、隐藏卡牌的信息量与 cost 收支。暂不扩展地图。
