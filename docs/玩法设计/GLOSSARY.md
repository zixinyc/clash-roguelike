# Clash Roguelike 玩法术语

用于统一项目讨论中的称呼，仅记录含义；具体规则见玩法草案和模式讨论文档。

## Language

**cost**：
小队共用、在同一局内跨战斗保留的资源，用于支付出牌费用与购物价格。
_Avoid_：将能量与金币作为两个独立钱包描述当前设计。

**联机猎人模式（hunter）**：
一名玩家先行动若干次地图行动、其他联机玩家随后直接追赶并与其对战的模式；被追杀者通关则胜利，被追杀致死则失败。
_Avoid_：把 hunter 默认为单个角色、职业或技能名称。

**被追杀者**：
联机猎人模式中先行动、以通关为目标的玩家。
_Avoid_：在未确定人数与控制方式前，将该玩家直接等同于一个战斗角色。

**猎人**：
联机猎人模式中后续参与追杀的玩家。
_Avoid_：将猎人默认定义成电脑敌人。

**全速追赶**：
猎人专属的快速地图移动行动，通过放弃本次发育收益获得更快移动。
_Avoid_：默认被追杀者也有此行动，或将建议的两节点速度当成确定规则。

**最后出现的位置**：
猎人离开对被追杀者可见的范围后，保留的最近一次可见位置。
_Avoid_：把旧位置标记当成猎人的实时位置。
