# 五层远征与敌方强化方案

状态为已接入工作区，数值按首版方案，等待试玩验收。

## 规则

- 废林远征最多五层。第 1～4 层 Boss 战结束后现有奖励照常处理。继续进入下一层之前，必须从三张敌方强化中选择一张。
- 坚壁使敌方最大生命 +20%、攻击伤害 +5%。均势为 +12% 和 +10%，凶袭为 +6% 和 +16%。同一项可以重复选择。所有加成在基础值上相加。从下一层开始覆盖普通战、精英、巡逻和 Boss。
- 最大生命在每场战斗初始化敌人时计算。伤害在敌方命中进入护盾结算前加成，拼点威力与速度照旧。
- 第五层 Boss 胜利演出播完后直接进入全局胜利画面，提供返回主菜单。胜利时写回队伍状态，结束本局。第五层普通战、精英和巡逻胜利走原有流程。

## 接入

- `ForestRun` 记录过层选择、累计倍率和远征胜利。强化与奖励在规则层结算，推进层数的函数校验强化已选且层数未达上限。
- `exploration_map.gd` 复用过层弹窗，按战斗正式结束的信号打开胜利画面。开战参数从 `planning_ui.gd` 传给 `battle_rules.gd`，每场独立计算敌方生命和伤害。
- 验收包括第 1 层必须选择，连续四次叠加覆盖各类探索敌人，第五层普通战继续探索、Boss 失败走败北、Boss 胜利直达通关，以及重开复位。完成后同步 `agent.md` 和代码全景。
