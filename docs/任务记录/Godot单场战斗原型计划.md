# Godot 单场战斗原型计划

日期：2026-10-29
状态：首版已完成并验收

## 目标

制作可运行、可操作的 Godot 单场战斗演示，以手牌选择、小队出招和拼点演出验证游戏核心体验。

## 首版范围与假设

- 使用 Godot 4、GDScript，程序绘制原创角色与场景。
- 演示配置：3 人小队、共用手牌与 cost 钱包；角色与牌之间的分配方式用于验证，不代表最终设计。
- 包含选角色、选牌、选敌人、拼点翻币、破币、追击、伤害、失败退款、回合结束、战斗胜败和重新开始。
- 每回合 3 张上限、基础收入及退款率作为原型参数，明确标注为测试值。
- 当前只实现单场本地战斗；不增加联机、地图、商店与复活系统。

## 工程方案

- project.godot 与单个主场景作为入口。
- 独立战斗规则脚本维护状态、随机数和结算事件。
- 战斗舞台绘制背景、角色和特效，按事件播放演出。
- UI 使用 Control、锚点与容器，参考分辨率缩放；支持鼠标及基础键盘操作。
- 程序合成简单音效，无外部美术音频依赖。

## 执行步骤

1. 检查 Godot 环境，建立项目配置与规则模型。
2. 制作战斗画面、手牌、目标和角色选择。
3. 接入事件驱动演出、回合与胜败流程。
4. 运行引擎导入与规则检查，启动实机截图并验证交互。
5. 补充运行说明、演示截图及实际验收记录。

## 验收标准

- Godot 项目导入与脚本加载无错误。
- 可以进行至少一回合操作，cost、手牌和出牌上限正确变化。
- 拼点失败只按实付费用退一次，平局有上限。
- 规则结果不依赖动画速度；同种子同操作结果相同。
- 可完成胜败结算并重新开始。
- 实际查看至少一张游戏截图，检查文字、布局和战斗区域；明确记录未验证项。

## 环境记录

初步未在 PATH 中找到 Godot，继续检查本机便携版本。若需要下载引擎，取得用户对下载与运行官方便携版的授权后再执行。

用户已明确授权下载并运行 Godot 官方便携版。实际使用 Godot 4.7.2-stable，下载发布文件并核对 SHA-512 后解压至项目 .tools 目录。使用进程级 APPDATA 与便携编辑器目录，把运行数据保留在项目工具目录。

## 实际结果与验收

- 本地 battle-demo 包含 project.godot、主场景、独立规则、舞台、卡牌、主界面与合成音效脚本，以及双击启动脚本。
- 交付了 3 人小队、5 张手牌、两名敌人、两类卡牌、拼点与破币、按剩余硬币攻击、护盾、cost 收支、回合收入、出牌限制、胜败及重开。
- Godot 导入与脚本加载通过，无 GDScript 错误。
- 215 项规则检查通过，覆盖无效操作、费用不足、行动上限、失败仅退一次、护盾、收入、敌方行动消耗、60 组种子的确定性、连续平局结束、胜败和重开。
- 1440×900 与 1000×650 的实际渲染冒烟检查通过；键盘选人、选敌、选牌、空格出牌、战斗胜利、失败和重开均运行验证。
- 已查看战斗初始、选牌、拼点、胜利及较小窗口截图。演示在第 2 回合取得胜利。
- preview 保存初始、拼点与胜利截图；test-output 保存自动验收截图。
- 修复了快捷键与聚焦按钮的空格冲突、自动演示期间重复输入、卡牌变少后过度拉伸，以及加速时伤害数字重叠。
