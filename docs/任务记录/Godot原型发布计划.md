# Godot 原型发布计划

日期：2026-10-29
状态：发布完成

## 目标与范围

按用户要求把本地 Godot 单场战斗工程发布到 zixinyc/clash-roguelike 的 main 分支，让他人可以下载、运行和修改。

## 方案与约束

- 上传可编辑的 Godot 工程、脚本、测试、UID、运行说明和预览截图。
- 采用 MIT 许可证允许使用、修改与再分发，要求保留许可和版权声明。仅覆盖本仓库原创内容，第三方内容遵守各自许可。
- 不上传 .tools 引擎与下载文件、.godot 缓存、test-output 运行输出和本机配置。
- 完善陌生机器的运行步骤：下载源码 ZIP，使用 Godot 4.7.2 标准版导入 battle-demo/project.godot 并按 F5。启动脚本支持指定 Godot 路径。
- 基于远端最新 main 创建提交，用非强制更新和预期提交值避免覆盖其他成员修改；其他分支不变。

## 执行与验收

1. 核对远端内容与许可证状态，整理待发布文件。
2. 更新下载、运行、许可说明与文档导航。
3. 在不使用本机导入缓存的干净副本中导入与运行规则测试，验证启动脚本的引擎参数路径。
4. 上传并以一次提交更新 main，回读树和关键内容核对。
5. 确认预览 PNG 正确上传，排除工具、缓存及凭证，记录最终提交与限制。

本次提供可编辑源工程，不承诺没有 Godot 引擎也能运行；独立可执行发行包不在本次范围。
