# 文档分类整理计划

日期：2026-10-26
状态：整理已完成，等待远端发布与回读验收

## 目标与范围

把现有 docs 文档按用途分入玩法设计、技术调研、协作指南、文档讨论和任务记录五个目录，保留原文，更新全部相对链接和项目首页。为技能想法与 hunter 建立讨论文档入口，不替用户猜测 hunter 的含义。

## 方案与执行

1. 读取 main 的最新提交和所有文档，使用远端内容作为整理基准。
2. 保存本计划；按路径映射移动文档，创建讨论目录与简短填写结构。
3. 更新主导航、首页及文档间链接；检查没有遗漏文件或断链。
4. 用一笔可追溯的提交同步 main，采用非强制更新及提交预期值保护，保留现有其他分支。
5. 回读远端文件、目录和提交，记录验收。

## 验收标准

- 现有文档全部保留并归类，所有相对链接指向有效文件。
- 从项目首页能进入分类导航和讨论文档。
- 技能想法与 hunter 是 docs 内的文档入口，不以分支名称冒充目录。
- 远端与本地一致，其他分支不被改写。
