# 战场与废林视觉改版

目标：让战场和地图看起来属于同一个世界，并让角色、敌方意图和可走格更容易识别。

## 视觉方向

- 战场采用雨夜废站，冷色远景、少量暖色灯火，角色与行动格保持清晰。手牌区延续按角色切换的交互，以角色色和费用、威力对比作为视觉重点。
- 废林采用俯视手绘林地，把原来的相邻格、迷雾、节点和小队位置叠在同一张连续地形上。金色边界标出可达格，事件、补给、战斗等通过文字和图形区分。
- 两张概念稿用于确定构图与氛围。游戏内使用独立背景图，由 Godot 绘制真实状态、可点击控件及迷雾。

## 实施与验收

1. 生成战斗和探索概念稿，以及无文字、无控件的背景素材。
2. 将素材接入战斗和地图场景。地图交互沿用现有位置、相邻移动和揭雾规则。出口守卫战仍在玩法讨论中。
3. 检查战场行动箭头、生命、手牌和地图地点的对比度。运行两种窗口大小的界面检查，以及战斗与地图回归。

## 实施结果

战场已接入雨夜废站和七名角色立绘。废林已接入连续地形、迷雾、节点配色、可达格边框与队伍侧栏。下列图片为内置 ImageGen 生成，游戏素材放在 `battle-demo/art/`，概念稿放在本目录的 `视觉预览/`。

- 1000×650 和 1440×900 均通过实际渲染及战斗界面回归。
- 716 项战斗规则断言，以及角色牌、敌人、地图与节点测试通过。
- 另走查补给、事件、营地、精英战及 cost 继承。
