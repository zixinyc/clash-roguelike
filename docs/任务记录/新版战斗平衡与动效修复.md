# 新版战斗平衡与动效修复

范围为 Godot 随机废林与单场战斗。基线为本地 196f69d。使用灰烬、ZiXi、ZiXingYC 及同一批战斗种子，观测首份资源、因果律满层、战斗长度、胜负和承伤。

1. 校正探索战斗初始化、战后回写和下一层开门条件。
2. 缩短两名角色的首轮成长准备，令自动安排理解强化、记忆配方和拼点目标。
3. 恢复选牌上浮及战斗受击反馈，保留演出倍速。
4. 对照同种子模拟及角色与探索回归。以真人体验为后续平衡依据。

## 实装

- ZiXi 拼胜获得 2～3 层超形上学，存活拼败获得 1 层。强化结算获得 1 层因果律，赢且分差至少 5 时获得 2 层。自动安排会攒到三层因果律再优先安排强化终符。
- ZiXingYC 单方面攻击补观测。残差连接实际攻击额外写入观测，拼败存活时也能用已有记忆整理。被删除的昨天拼胜也能写入反思。推理与检索从首份起生效，第三份达到上限。
- 地图战从当前探索状态读取费用、最大生命、道具与遗物。战后由地图规则统一发放 6 / 10 / 15 cost 的普通 / 精英 / 首领奖励，普通胜利后存活队员恢复 6 HP。地图回写已用道具，每层重新获取自己的烬核。巨像由 180 HP 调至 210 HP，每回合提供两次可拼点行动，奇数回合第二招较轻。
- 卡牌选中上浮 10 px。战斗接触时播放冲击、火花、闪白和震动。默认演出 ×1，可切换 ×2 和 ×4。程序火花可在贴图缺失时显示。

## 对照与验收

五组敌人各用种子 1100～1219，分别跑同一组初始阵容、完整初始 HP 与 30 cost，各 600 场。沿用各版本自动安排作为玩家输入，每场最多 12 回合。统计基于实际战斗事件快照，满因果律以曾达到三层计，包括终符清空之前。

| 指标 | 基线 | 修订后 |
| --- | ---: | ---: |
| ZiXi 获得因果律 | 0 / 600 | 461 / 600 |
| ZiXi 因果律达三层 | 0 / 600 | 316 / 600 |
| ZiXingYC 获得语料 | 0 / 600 | 466 / 600 |
| ZiXingYC 获得至少两类语料 | 0 / 600 | 183 / 600 |
| 小队每场平均损失 HP | 48.36 | 36.10 |
| 胜利 | 599 / 600 | 599 / 600 |

修订后成功获得首份语料的对局平均在第 2.03 回合获得。各场从满血独立开始，数据适合比较成长节奏与单场承伤，完整探索强度仍待真人试玩。
