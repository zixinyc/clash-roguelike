# 猎人模式记录计划

日期：2026-10-26
状态：执行中

## 目标与范围

将用户对 hunter 的解释记录到原讨论文档：联机猎人模式、一名玩家先行动若干回合、后续玩家追杀、被追杀者通关胜利或被追杀致死失败。同步讨论导航和术语说明。

## 约束与步骤

读取远端现有内容后更新。保留猎人如何追赶、回合如何同步、具体先手数量、人数和其他死亡情况为待定项，不把建议当成已确认。当前只记录玩法，不实施联机。

## 验收标准

- hunter 不再显示主题含义未知，已确认规则准确。
- 通关和追杀死亡的胜负描述以被追杀者为视角，不擅自补全全部阵营胜负。
- 新增文档和导航相互可达，远端回读内容一致。
