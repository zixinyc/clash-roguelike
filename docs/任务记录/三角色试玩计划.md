# 三角色试玩实施计划

目标：在现有单场战斗中提供蓄势、冒险、援护三名角色，让玩家通过现有通用手牌体验区别。
范围：保留现有卡牌与行动规划；为三名队员分别增加可见的角色能力，并记录当前设计为试玩参数。
方案：蓄势者拼点获胜积累准备，下一次拼点使用；破阵者使用高费用牌获得拼点加成但失败受伤；援护者防御时为其他存活队友提供护盾。所有状态进入快照并通过战斗日志呈现。
步骤：修改结算和界面说明，补充规则测试，运行已有测试及启动检查。
验收：三种能力各自能触发，失败和目标退场等边界不破坏原规则；演示可启动；记录验证结果和限制。

## 验收记录

- 角色能力采用与现有通用手牌组合的被动试玩版：三项被动已实现，并显示角色说明和触发日志；专属技能牌、自选加注和指定援护对象尚未实现。
- Godot 4.7.2 编辑器导入通过；现有规则测试 716 项通过；新角色测试通过（蓄势获取与消耗、高费加成与失败损失、援护与阵亡边界）。
- 自动规则测试不代表完整视觉、操作体验或数值平衡验收；需用户实际试玩。
