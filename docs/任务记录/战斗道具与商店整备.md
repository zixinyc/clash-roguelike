# 战斗道具与商店整备

战斗右上角显示道具数量，规划期间可展开查看并使用。配队入口集中在开局和商店。验证开局选人、商店重开与保存、战斗使用以及回地图后的道具数量。

- 战斗中逐项显示数量、效果和不能使用的原因，道具成功生效后刷新库存和战斗状态。野战膏药只治疗受伤的存活队员。
- 交易完成后商店继续提供整备，同一摊位仍维持单次交易。重新上阵的队员保留当前生命和生命上限。
- Godot 4.7.2 Windows 下通过 18 个无头回归和 3 个现有视口测试。另在 1000×650 与 1440×900 实际渲染并模拟鼠标点击，覆盖开局配队、商店购买、保存及战斗使用烟雾弹。
- `test_map_nodes.gd` 覆盖商店重开、编队和牌组保存、重新上阵生命、消耗品回写。`test_forest_map.gd` 覆盖道具效果及使用限制。
