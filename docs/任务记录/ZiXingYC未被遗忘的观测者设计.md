# ZiXingYC｜未被遗忘的观测者 · V0.6 试玩设计

目标是在现有「阵容与卡组」加入可选角色 ZiXingYC。HP 40、Speed 7–9，保留 V0.5 的记忆、语料、过载和永久成长。现有配置页用于勾选卡牌，点数集中在人物脚本，方便继续改数值。使用 `battle-demo/art/zixingyc-placeholder.png` 作为本地占位贴图。

MiniMax Code 已完成阵容和战斗接入。本轮验收对照下列结算规则检查角色源码，收拢重复的整理逻辑，再运行角色、战斗、地图与阵容入口回归。

三张进攻依次按 3＋2×正面数、3＋3×正面数、4＋3×正面数计算基础伤害。攻击期间用剩余硬币重新掷币。终符要求至少一份语料及本次拼胜，5 cost，保留原公式和每战最多发动两次。次数按轰炸实际发动扣除。已有的常规固定伤害加成对每个命中目标应用一次；每个目标各自扣护盾。

按原型正面率及破币规则，不带状态的「注意力机制」对裂影斥候的「穿隙」胜率约 88%，对「余烬斩」约 40%。终符裸拼对同点型「破晓」约 77%。速度 7–9 对裂影斥候的 4–7，抢接条件约 92% 成立，接下的牌能否拼赢仍由硬币决定。推理或检索收益要各有两份对应语料才出现，短局通常先有过载管理和生成收益。

## 随牌整理与结算

- 每份记忆以获得顺序编号，保存原始类型和已整理状态。整理按符卡指定的类型与顺序自动执行，玩家通过选牌确定整理方式。
- 「注意力机制」实际结算后，由观测→关联→反思生成推理语料；「自指悖论」拼胜并成功对活目标施加削弱后，由反思→关联→观测生成检索语料。两者分别使用每种类型最早的一条未整理记忆。
- 「残差连接」攻击结算后，取最早三条未整理记忆，按观测→反思→关联的类型顺序稳定排列，生成语料。含重复类型的组合允许整理。同种类型内部维持写入顺序。
- 先完成符卡自身的伤害或写入，再尝试整理。本次新获得的记忆也可以整理。同一回合只有一次成功整理；材料不足时留待后续合适的牌。角色已退场或行动取消时无整理。
- 拼点胜负以整场拼点结论为准。先记录基础观测或反思，再记录卡面额外的记忆，合计遵守每回合三条上限。「注意力机制」拼赢总计最多获得两条观测。「被删除的昨天」拼输在卡牌效果中追加一条反思，同样受上限限制。
- 「自指悖论」的削弱标记归目标所有，仅在目标下一次与 ZiXingYC 拼点时消耗。若目标在拼点开始时已经受削弱，本次拼胜攻击附加 3 点。「被删除的昨天」减伤只限本次拼败受到的攻击，每段伤害乘 0.7 向下取整后再抵护盾，拼胜的护盾使用原型当回合的护盾期限。
- 语料整理成功后立即更新过载、检索及生成。推理额外收入在下回合开始时到账，最高 +2。当前原型没有全局 Cost 硬上限，后续若加入上限，推理遵从同一限制。
- 终符用发动前已有的语料计算伤害，本次攻击后的整理只影响后续行动。记忆、状态和语料随新战斗清空。

## 实现与验收

1. 添加独立人物数据、记忆和五张牌，登记到角色名单及卡组配置。已有阵容入口继续选择 1～3 名角色和手牌。
2. 复用拼点、费用、护盾及伤害事件。在符卡结算末尾根据牌面定义尝试整理。
3. 在已有手牌区显示未整理数量、各记忆类型、过载罚值、语料层数及本轮整理状态。选牌提示显示该牌的整理配方与当前材料是否充足。
4. 测试记录排序、重复 ID 与重复提交、3/5/8 阈值、取得两份语料后的收益、卡牌控制与护盾、终符伤害与两次限制。检查单人和混编、原角色及地图回归。

## 验收结果

- 残差连接先取最早三条，再按配方排列。注意力机制拼败后仍可用刚写入的反思整理，僵持时可整理已有记忆。自指悖论只对攻击后仍存活的目标写入关联和削弱。生成语料对专属及通用攻击都生效，每次攻击只计一次。
- 整理配方由符卡配置提供。结算一次选取并标记记忆，整理日志使用实际选中的记录。界面提示在本回合已整理后会明确显示状态。
- Godot 4.7.2 通过 102 项角色检查。1440×900、1000×650 各通过 103 项，覆盖配置页面、一次实际交锋和占位图显示。原角色、战斗、地图和目标引导断言通过。拖拽与目标引导测试在退出时仍可能报对象释放警告。长期成长速度与真人数值平衡留待试玩。
