# 先选牌与技能剩余次数

本次交付一份接入指引和一张出牌预览。出牌设计等待试玩范围确认，先在规划界面落地，保留原有伤害、拼点和结算顺序。

![先选牌的规划界面预览](视觉预览/先选牌.png)

## 当前卡在哪里

现在选牌确实会自动换到当前一组对应类别的格子，但它只在当前角色这组格子里跳转。该格已经占用、该组已满，或少人队的补格还有余量时，玩家经常要自己换格。换到别的角色或类别还会取消选牌。大部分失败由 `can_assign()` 在检验「这张牌＋这个格子＋这个目标」后给出，结果通常出现在下方提示或日志里。没接触过这套格子规则的玩家，看到的可能只是牌点了，却不知道下一步点哪里。

另一个缺口在于次数。普通牌通常是当回合只能安排一次，撤销后可以再安排，下一回合恢复。咲夜的时停回合允许重复安排普通牌。「咲夜的世界」在回合锁定时记为本场已用，「记忆的终点不存在」只有实际拼赢发动才扣本场次数。玩家需要同时看到「这张牌还有几次」和「现在为什么用不了」。缺一份语料、费用差一点、没有可用目标，都会令一张还有次数的牌暂时无法安排。

## 建议操作

1. **点牌。** 牌面常驻显示费用、剩余次数、已安排或主要卡点。专属牌直接用其角色。通用牌沿用当前角色，若只有其他角色能用，显示可选角色和原因。只有查不到合法组合时才把牌置为不可安排，查看说明仍可用。
2. **点目标。** 我方类别格和补格由系统找，优先未占用的兼容格。敌方角色旁显示可点的意图，例如「迎击」「替队友接招」「单方面攻击」，并写实际将用的速度。敌方有多条有效意图时，逐条列出让玩家选；指向防御或空槽时，明确原攻击是否照常发生。纯护盾牌用「安排护盾」一步确认，带敌方目标的防御拼点牌仍选目标。
3. **查看已安排。** 牌旁和规划列表同时显示「谁用哪张牌、对哪个目标、是拼点还是单方面攻击」。可以点「改目标」或「撤销」。若两条我方行动会争同一条敌方意图，用与结算相同的优先级预览接招者；须拼点的牌会失去对手时，在锁定前指出哪张牌受影响。需要替换旧行动时显示原行动并由玩家确认。想细调速度或执行顺序的玩家，可展开「调整行动格」。
4. **准备交锋。** 继续由玩家确认整轮，确认前只预留 Cost。键盘路径保留数字选牌、方向键选意图、确认安排和 Esc 退回。动作只在确认提交后改变预留状态。
5. **看技能结算。** 在正在结算的牌上显示本次目标和结果。拼赢释放、拼败退费、被打断各有简短状态；大招在实际释放时才点亮，取消时在牌上直接说明原因。让反馈跟着牌和目标走，短结果和攻击动画一起显示。

## 次数和限制怎么显示

| 状况 | 牌面 | 选牌区或目标提示 |
| --- | --- | --- |
| 普通牌未安排 | `本回合可用 1 次` | 如果这张牌和别的牌抢同一个进攻格，等你确认后才更新各牌状态。 |
| 普通牌已安排 | `已安排` | `已预留 1 Cost`，显示目标。撤销后马上恢复可安排。 |
| 有整场上限的牌 | `本场剩 2/2 次` | 再单列「缺 1 份语料」「本回合已安排」等当前条件。ZiXingYC 拼败时，本场计数沿用实际发动时机。 |
| 费用不足 | `本回合剩 1 次` · `差 1 Cost` | `撤销一张已安排的牌，或使用可补费的道具`。精确的缺口按实际报价与可选格计算。魔理沙能借费时，预览要显示会消耗多少 HP。 |
| 兼容格已占 | `进攻行动已占用` | `可撤销「注意力机制」`。如果补格有空位且合法，直接选补格。 |
| 目标与拼点条件不足 | `需要拼点` | `只能选正在攻击的意图`、`速度 4，拦截需要快于 5`。原目标迎击和咲夜例外按现有规则解释。 |
| 牌已蓄能、角色冻结或退场 | `蓄能中`、`时停中`、`已退场` | 说明什么时候恢复或切换到谁。次数仍按规则层提供。 |

## 开发范围与验收

- 第一步接卡面次数、可用/已安排状态及能执行的失败提示。用规则层只读查询返回候选格、合法意图、精确原因与有效费用，沿用 `can_assign()`、配对优先级和角色计数；牌面和快捷键读取同一份结果，在选牌、撤销、用道具、切角色或新回合时更新。
- 第二步用先选牌的路径代替默认双下拉框操作，将原行动格入口放进「调整行动格」。计划清单允许改目标和撤销，自动挑格能跨补格且保留已经安排的牌。确认后的目标与席位传给现有 `assign()`，操作前重新验合法性。
- 结算反馈用现有战斗事件标记正在结算的牌，补充演出中缺失的动作标识时沿用规则层事件协议。×1 和 ×4 都能看懂是哪张牌打出，以及为何失败或被取消。
- 普通玩家在 1000×650 和 1440×900 能看清费用、次数和限制，可以只用「选牌 → 点意图」安排攻击。新手看到费用差 1 时能从规划列表撤销一张牌，看到「缺 1 份语料」时知道要先用整理牌。覆盖防御、共用牌、两人补格、咲夜时停、魔理沙借费、两张牌争同一拼点、ZiXingYC 终符拼败及战斗重开。检查敌方技能在锁定前仍然隐藏。
