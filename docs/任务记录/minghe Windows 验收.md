# minghe Windows 验收

1. 核对当前角色脚本、主菜单、练习战、远征牌库和共有辅助槽。修复验收中复现的接线问题，保留现有角色设计。
2. 运行角色与战斗全套无头测试，抽查实际窗口。用默认队与 minghe 队在固定种子下对照单场和五层远征。
3. 在本机真实视口测主菜单、探索、战斗的空闲帧率、画布重绘和帧处理时间。记录当前工作区的结果。
4. 打包等剩余内容合入后再进行。届时用现有 Windows 预设导出，解压后测试 EXE 启动与角色入口。

## 当前工程验收

- 从主菜单的「单机模式」选择 minghe。林地探索起始牌库含清音起手和灵韵灌注，自由交锋可选择高血量沙包和全部已解锁符卡。
- 「共有辅助槽 · 空」常驻于战斗规划界面，在「自动安排」左侧。选中标有「辅助」或「防御」的手牌后点击放入，支持指定队友、换牌和撤销。实际窗口以 1000×650 和 1440×900 验证了空槽可见、援助目标、撤销、结算和换轮。
- minghe 的回声计数已在回合准备阶段重置。33 个无头脚本及 4 个真实视口测试通过，含 58 项 minghe 定向检查。双进程 PvP 未测试。

## 本机空闲负载

Godot 4.7.2，OpenGL Compatibility，RTX 5070 Ti Laptop GPU，1440×900，Dummy 音频。每个场景预热 2 秒后抽样 3 秒。测量的是主循环帧间隔和对应画布的重绘次数。

| 场景 | 主循环平均帧率 | 画布重绘次数每秒 | 帧间隔 P95 |
| --- | ---: | ---: | ---: |
| 主菜单 | 60.0 | 12.9 | 16.76 ms |
| 林地探索 | 60.0 | 15.2 | 16.68 ms |
| 单场战斗 | 60.0 | 19.9 | 16.69 ms |

## 数值抽样

默认队与「灰烬、长锋、minghe」各走 80 个相同种子。自动排牌下，五层直奔路线分别通关 74/80 和 77/80，整备路线分别通关 77/80 和 74/80。开局 45% 正面率下，对荒原掠夺者与狂暴飞龙分别赢 51/80 和 70/80，战术排牌两队均为 77/80。对烬心巨像的单场两队均为 80/80。

本轮抽样沿用现有排牌策略，覆盖同条件下的单场与五层对照。共有辅助槽已通过功能测试，模拟胜率未计入手动辅助槽策略。完整日志及截图位于 `battle-demo/build/minghe-acceptance-20261123/`。本次验收基于工作区，Windows 打包暂停。
