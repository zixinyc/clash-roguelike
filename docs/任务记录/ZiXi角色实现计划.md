# ZiXi｜几乎必然的观测者

## 目标与验收

为单场战斗增加 ZiXi 测试阵容，保留现有入口、原阵容、东方队和地图。人物代码放在 battle-demo/scripts/characters/，使用用户提供的小汐原图。验收以角色卡 V1.0、独立机制回归和实际出牌流程为准。

## 最小改动方案

1. 在 ZiXi 独立脚本定义 HP 50、四张符卡、两种资源、一次性拼点增益与护盾期限。经确认，速度采用 3–5。原目标仍可迎击，替队友接更快的攻击仍受速度限制。
2. 扩展现有阵容切换。ZiXi 测试阵容中由 ZiXi 替换长锋，灰烬和织火继续随队。沿用现有格子、共用手牌费用和敌方目标。在规则层增加强化选择、拼点与技能结算的钩子。保留其他角色的随机与伤害规则。
3. 在原有手牌区增加资源读数与强化选项。牌面显示 Cost、初始点和硬币。强化选择跟随该行动；撤销或换牌时可以退回规划阶段预扣的 3 层。立绘接入本地可选资源。
4. 加入专属回归测试，覆盖上限、回合限额、胜差、下一次拼点增益、强化选择和取消、翻币、拼输后护盾、跨回合护盾、轰炸顺序与清空。重跑原角色与地图测试，并核对可用的窗口尺寸。

## 结算口径

- ZiXi 三张专属攻击要求成立拼点并获胜后才造成伤害。普通攻击伤害逐枚重掷仍存的硬币，基础伤害只加一次，正面按 ZiXi 的独立伤害数值计算。基础牌面的拼点参数照角色卡。
- 强化消耗在规划时预扣，锁定之后取消行动时不回退。实际开始结算的强化即使拼输也会获得因果律，倒地则停止该效果。
- 收敛极限每次技能只改第一枚反面，覆盖拼点和随后攻击。攻击若自然掷出完整的三枚正面，获得额外伤害。
- 等对方最后一枚硬币破掉后，用这次交锋的最终分差计算超形上学，随后结算伤害、护盾与因果律。几乎必然单体追加按本次拼点时的因果律计，全体轰炸用新获得一层之后的数值。
- 鞅的护盾持续到下一回合结束，护盾扣除按较早到期的优先。此效果只接入 ZiXi。
## 平衡对照

裂影斥候速度 4–7，按双方行动格各自等概率取值，ZiXi 速度 3–5 时严格更快的概率为 1/12；5–7 时为 1/2。被攻击的原目标仍可迎击。中心极限定理的初始值 11 已超过普通余烬斩的最大值 10，因此保留角色卡原数值时，速度和大招对局是主要限制。
