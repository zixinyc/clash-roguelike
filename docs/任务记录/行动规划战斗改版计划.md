# 行动规划战斗改版

日期：2026-10-29
状态：实现与验收完成，已同步 main

## 已确认目标

固定每回合敌方先规划并锁定。玩家能看到行动类别、是否启用、公开速度与目标箭头，看不到敌方卡牌、威力、硬币数，不提供胜率。玩家响应阶段 180 秒，可修改撤销；准备完成提前结算，超时锁定已有行动，空格待机。角色支持多个行动格，速度按角色特性随机分配。暂不做地图与联机。

## 演示配置与边界

- 每个角色提供进攻、大招、防御三个分类格，每格最多一张，每人最多安排两次行动；全队上限改为六次，仍受手牌和 cost 限制。
- 灰烬速度 3–6，长锋 5–8，织火 2–5；敌方巡卫 2–5、哨兵 4–7。每回合各格独立抽取，安排/撤销不重掷。
- 原目标可以迎击，拦截队友的攻击需要严格更高速度；多次拦截以速度最高者优先，同速按稳定行动编号。没有接到拼点的我方攻击仍攻击对应敌人。
- 同速结算使用固定编号顺序；目标死亡则取消该次行动，不自动改目标；已锁定支付不退，避免隐藏自动决策。
- 防御格提供自身护盾，大招使用独立测试牌。每回合六张共享手牌。
- 普通平局重掷；必然平局判为僵持，双方不攻击，玩家返还实付一半。极端超过 100 次平局也按僵持处理，为本项目自定保护规则，并非宣称复刻参考游戏。
