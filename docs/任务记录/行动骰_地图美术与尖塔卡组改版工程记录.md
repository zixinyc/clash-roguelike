## 三、阶段 1 工程方案与拟改动代码清单

### 1.1 目标与规则边界

1. **初始 Cost（30 → 18）**：
   - `DemoBattleRules.START_COST` 改为 `18`（影响战斗初始 `cost` 与 `enemy_cost`）。
   - `ForestRun` 新增 `const START_COST := 18`，`carried_cost` 默认与 `initialize()` 均设为 `START_COST`。
   - `exploration_map.gd` 兼容字段 `carried_cost` 与 `_restart()` 统一引用 `ForestRun.START_COST`。
2. **1d4 行动骰子制度（`ForestRun`）**：
   - 常量：`DICE_MIN := 1`、`DICE_MAX := 4`、`FATIGUE_PENALTY_THRESHOLD := 6`。
   - 状态字段：
     - `dice_rolled: bool = false`（本回合是否已掷骰）
     - `last_dice_raw: int = 0`（原始 1d4 点数）
     - `last_dice_penalty: int = 0`（疲劳扣减点数）
     - `action_budget: int = 0`、`actions_left: int = 0`（掷骰前均为 0，掷骰后等于 `maxi(1, raw - penalty)`）
     - `dice_rng: RandomNumberGenerator`（独立随机流，使用 `seed_val ^ 0x51A7D1CE` 初始化）
   - 核心方法：`roll_action_dice(forced_raw: int = -1) -> Dictionary`
     - 处于 `finished`、`in_battle`、存在 `pending` 弹窗或本回合已 `dice_rolled` 时拒绝并返回 `{"ok": false, "reason": ...}`。
     - 支持 `forced_raw`（1～4）便于单元测试覆盖边界（如 `raw=1`、`raw=4` 与高疲劳 `fatigue>=6`）。
   - 移动与回合流转：
     - `move_error()`：未掷骰时优先拦截，返回 `"请先掷出本回合行动骰决定步数。"`。
     - `phase_text()`：未掷骰时返回 `"等待掷骰"`。
     - `end_turn()`：未掷骰或未消耗任何步数均视为休整（`rested = not dice_rolled or actions_left == action_budget`）；切入下一回合后重置 `dice_rolled = false`、`action_budget = 0`、`actions_left = 0`。
     - `advance_to_next_floor()`：进入新楼层同样重置骰子状态并按新种子重设 `dice_rng`。
3. **探索 UI 掷骰交互（`exploration_map.gd`）**：
   - 顶部 HUD 新增 `roll_dice_button`（`🎲 掷行动骰 (1d4)`），未掷骰时金色高亮提醒。
   - 点击后播放约 `0.42s` 的骰面翻滚动画（`⚀ ⚁ ⚂ ⚃` 快速轮播 + 文本反馈），动画结束调用 `run.roll_action_dice()` 提交步数并点亮地图可达节点。
   - 提供同步辅助方法 `roll_dice_instant(forced_raw: int = -1)` 供自动化测试无等待验收。
   - 地图画布在未掷骰且非弹窗/战斗状态下显示醒目的底部/顶部轻量提示条（`"请点击顶部「掷行动骰」决定本回合可行动步数"`），未掷骰时点击相邻节点会给出提示并高亮骰子按钮。
   - 步数耗尽（`dice_rolled and actions_left == 0`）时高亮「结束回合」按钮。

### 阶段 2B · 战斗行动槽视觉与交互引导优化（规划方案，2026-11-20）

> **痛点诊断（基于 `battle_stage.gd` 与 `planning.png`）**：当前行动槽仅 `40×34`、装牌后看不到牌名与费用、角色 2 次行动上限无明显槽位反馈；选牌后我方合法接收槽不高亮；拖拽过程无实时迎击/拦截文字反馈；敌我多条箭头叠加杂乱。

#### 2B.1 五大核心优化点
1. **行动槽重塑（更大、信息更完整）**：
   - 槽位尺寸升级（约 `54×46` 圆角/切角战术牌位），顶部独立大号速度角标（如 `⚡5`），中部清晰区分 `攻 / 大 / 防` 徽标与底色；
   - **已装牌直显**：安排卡牌后，槽内直接显示 **卡牌简称 + 费用小圆标**（如 `断轨 3`、`守夜 1`），强化牌附带星标；
   - **单角色行动额度可视化**：每组行动槽旁显示本组行动点指示（如 `●○ 1/2`），排满 2 次后其余空格自动灰化斜纹并标「已满」。
2. **三步式动态视觉引导（选牌 → 瞄准 → 确认）**：
   - **选牌后点亮我方接收槽**：选中手牌时，能承接该牌的我方行动槽立刻呼吸高亮并浮出小提示（攻击/大招标 `拖向敌方`；防御牌标 `点击安排`，并支持 **直接点击该高亮我方防御槽完成安排**）；
   - **敌方槽直接挂关系标签**：选中攻击/大招牌时，敌方行动槽附带紧凑彩色短标：🟢 **迎击**（必拼点）/ 💠 **拦截**（高速替队友接招）/ ⚪ **单打**（单方面攻击）/ ⛔ **不可**（速度不足或不可选）；
   - **拖拽实时判定胶囊**：拖出鎏金引导箭并靠近敌方槽时，吸附高亮并在光标旁实时显示判定结论（如 `⚡ 高速拦截 · 速度 7 > 5 · 替灰烬接招` 或 `✖ 速度 4 ≤ 5，无法替队友拦截`）。
3. **直觉交互补齐（保留原有拖拽与下拉框 100% 兼容）**：
   - 选中攻击/大招牌后，支持 **「直接点击高亮敌方合法槽即可安排」**；
   - 选中防御牌后，支持 **「直接点击高亮我方防槽即可安排」**；
   - **右键点击已安排的我方槽** 快速撤销此格并释放预留 Cost。
4. **焦点箭头降噪**：
   - 默认规划态非焦点箭头柔和降透；当悬停/选中槽位或拖拽时，仅突出与当前焦点直接相关的敌我箭头（加粗 + 流动光点），无关箭头压低，并在受击角色脚下点亮红色预警圈。
5. **动态步骤引导栏**：
