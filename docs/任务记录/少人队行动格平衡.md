# 少人队行动格平衡

目标：让单人和双人随回合追上三人队可安排的行动数。
方案：按开战人数，每过一回合补一组三种格，达到 9 格即停止。每组可选两格，单人实际行动上限 2→4→6，双人 4→6，三人维持 6。双人的补充组先分给排在第一位的存活队员。退场不会追加额度。保留咲夜时停三格、卡组去重和 cost。
步骤：集中行动格生成与限制、适配界面和拖拽、验证增长及既有战斗。
验收：三个队伍人数的增长正确，新增格可实际安排和结算，三人基线与角色专项、地图回归通过。强度由试玩确认。

验收：Godot 少人专项通过，验证 1～3 人格数增长、额外格安排与结算、每组上限、重复牌限制及咲夜时停。1000×650 窗口已截图检查，原战斗 716 项、ZiXi、东方角色、配置、地图与图形自动流程回归通过。真人强度待试玩。
