# 暗黑奇幻敌人与角色接入计划

目标：在单场战斗原型中试玩三种普通敌人与一名精英，并让角色与敌人的定位清楚可见。
范围：保持每场两名敌人和现有规划交互，新增两组可切换的敌人组合；实现敌方各自的攻击或支援行为与可辨识的提示；沿用现有三名角色能力。视觉采用现有原型绘制与概念图辅助，单独可动画素材未制作。
验收：四种敌人可在两组战斗中出现，技能能按时结算、角色和敌人退场后不误触发；旧规则测试与新增敌人测试通过，界面可启动。数值为试玩草案，留待人工平衡。

## 实施与验证记录

已实现两组敌人切换、四种敌人差异、敌人基础图形区分和战斗日志。原有规则 716 项断言、角色能力测试和敌人效果测试通过；Windows 图形模式自动战斗流程通过。敌组切换和第二组的人工交互、完整数值平衡尚未验证。角色专属技能牌、精英蓄力循环、真正的手绘立绘与动画仍未实现；概念图已保存为旁边的 PNG 文件。
