# 自由配队与独立阵容页计划

目标：战斗前在独立页面自由选择 1～3 名已有角色与敌人组合，支持任意角色单走和混编；清空配队后不可开始战斗。
范围：灰烬、长锋、织火、ZiXi、咲夜、灵梦；保留单场战斗和地图原有入口、角色机制和技能；未来 UI 更新与阵容 Buff 仅记入 idea。
方案：先梳理角色固定下标与技能归属，按角色身份映射队伍中的位置，兼容已有阵容和地图；配置页提供角色选择、清空和开始战斗。不能用隐藏、假阵亡占位代替真实配队。
步骤：实现身份和席位适配；接入配置页与战斗返回；验证六角色单人及典型混编、正确手牌、目标、胜败、原阵容和地图回归；进行图形操作检查。
验收：所有角色均能单独选择和进入战斗，出战者之外没有额外角色或行动；角色专属效果正确；可混编 1～3 人且可清空；原功能回归通过。伤害平衡待人工试玩。

卡组扩展：配置页按通用牌与已选角色分组，允许逐张勾选；默认带齐当前可用牌。开战要求至少一名角色和一张牌，每回合以所选牌恢复测试手牌。地图仍从原战斗场景进入。验收增加空阵容与空卡组限制、换队后的卡牌归属和重返配置页。

## 验收结果

六名单人均通过入场、角色归属、出牌、战斗结算和返回。验证了混编、选敌、清空、空卡组限制和所选牌在下一回合保留。1440×900 和 1000×650 的图形测试通过，截图保存在 battle-demo/test-output/。原规则 716 项、现有角色专项、地图与节点以及原规划界面回归通过。此前已有的目标提示测试退出时仍有 ObjectDB 残留警告。首版沿用原敌组和行动上限，单人强度待试玩。
