# 咲夜与灵梦试玩计划

在单场战斗提供「东方队」测试阵容（灰烬、十六夜咲夜、博丽灵梦），复用行动规划、拼点、费用和事件播放。原阵容和地图继续使用现有入口与队伍。交付代码和验证结果。

1. 登记八张符卡与角色数值，接入速度接招、回合状态、退治、停时与梦想天生。
2. 接入测试阵容切换、选牌和目标预览。沿用占位角色，无需新增图片。
3. 用 Godot 检查旧规则和地图，实测新牌预留、扣费、拼点、期限、行动限制及决胜。

## 试玩口径

- 缺省硬币数为一枚。进攻符卡标注的伤害按满币总值实现，破币会减少伤害段数。银色小刀和私人空间的伤害加成每次攻击计一次。退治在命中扣除生命时叠加。
- 秒表、私人空间、停止时间和退治引爆生效于下一回合。私人空间使用防御格，增益持续一回合。咲夜的世界在锁定扣费时消耗本场次数，行动结算成功才会停时。
- 梦想天生拼胜获得一层梦想宝玉，第三个后续回合结束时，按每个目标自己的退治层数分别计算伤害。满三层宝玉且目标有三层退治时，该目标受到 45 点伤害。
- 幻想乡本土敌人用 `gensokyo_native` 标记。目前两组原型敌人未标记。

## 平衡对照

使用原型我方 65%、敌方 50% 正面率，按失手破一枚硬币与平局重掷计算单场拼点，先排除速度增益、地域加成和其他状态。

| 符卡 | 对余烬斩 | 对破晓 |
| --- | ---: | ---: |
| 杀人玩偶（2 cost） | 47.4% | 0.4% |
| 梦想妙珠（2 cost） | 73.0% | 3.3% |
| 封魔阵（4 cost） | 56.6% | 1.2% |
| 梦想天生（5 cost） | 100% | 71.4% |
| 现有我方同名破晓（4 cost） | 99.8% | 76.6% |

封魔阵对强大招的胜率很低，受益于退治或秒表先铺状态。咲夜的世界可以对未启动的敌方行动格释放，5 cost 低于现有每回合 +8 的收入。试玩时重点观察它能保证跳过多少敌方行动，以及是否让两组敌人的关键回合失去压力。
