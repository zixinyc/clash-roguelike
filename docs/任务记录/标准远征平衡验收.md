# 标准远征平衡验收

## 验收计划

1. 按正式探索开局配置模拟普通遭遇、巡逻、精英和首领，分开统计单场胜率与五层远征通关率，以 80% 为验收线。默认三人队为主，额外测三人组合、双人与单人。
2. 用可复现种子抽查五层地图。检查行商保底、首领前可达性、绕路代价、命运门距离、普通战可绕过程度。
3. 使用真实战斗和探索规则结算，记录路线与操作策略。节点随机性超出整备可接受范围时，优先收紧关键服务点的位置并比较前后结果。

## 验收口径

- 标准远征、正式开局卡组、水银骰子、野战膏药和浓缩烟幕弹。单场从满血与 18 Cost 开始，覆盖三种普通敌组、三种精英敌组和烬心巨像，分别使用 45% 和 60% 的拼点正面率。
- 每个阵容、正面率、敌组和操作策略组合跑 200 个固定种子。每个完整远征的阵容、路线和操作策略组合也跑 200 局。远征携带生命、Cost、遗物、道具和牌库进入下一战，首领结算后统一选「坚壁」。每场至多模拟 40 回合，超时记为未获胜。
- 「自动安排」调用游戏内的排牌按钮逻辑。「战术策略」用公开的行动与速度规则、卡牌数值和敌方技能数据评估拦截、集火与单打。两者使用同样的道具策略。战术脚本比玩家拥有更完整的敌方技能信息。
- 「直奔」优先寻找避开战斗格与巡逻闭环的关底路线，途中经过的节点正常结算。「整备」计划访问两座命运门、神龛、一场普通战、休息营地、锻台和行商。「两站路线」只主动前往首座命运门和行商。路线脚本提前读取整张地图，每一步仍走真实的掷骰、迷雾和移动校验。

## 节点随机性

第 2～5 层各抽查 500 个种子，调整前后使用同一组种子。首层是手工地图，单独测了一次。绕路距离以地图最短步数计算，安全相通另行验证。

| 第 2～5 层 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 每层有一处行商 | 2,000/2,000 | 2,000/2,000 |
| 可避开战斗格与整条巡逻路线到店 | 1,432/2,000（71.6%） | 2,000/2,000 |
| 先到行商再去归途石门的额外步数 | 0～2 格 | 0 格 |
| 先到行商再去烬心祭坛的额外步数 | 2～12 格 | 0～2 格 |
| 入口到首座命运门的安全步数 | 2～7 格 | 2～3 格 |
| 可避开普通战、精英战和巡逻直达归途石门 | 1,910/2,000（95.5%） | 2,000/2,000 |

第 2～5 层把行商移到两个首领入口之间，行商与两个入口各相隔一格。行商所在行随种子变化，从西区到行商有一条预留通路。首座命运门固定在入口向东两列，上下有一格浮动。普通战、精英战、补给、遗迹和其他支线节点仍可换位置。首层沿用手工布局，行商距归途石门 1 格、距烬心祭坛 2 格。

固定整备点解决了行商的位置风险，也使每个随机层都有一条可跳过普通战的路线。首领奖励足以支持直奔五层的策略时，探索支线的价值需要从战利品和路线收益上衡量。

五层远征通关率（行商布局调整后、增加战前命运门前，每格 200 局）。

| 阵容 | 直奔＋自动 | 直奔＋战术 | 整备＋自动 | 整备＋战术 |

默认队整备＋自动赢了 162/200 局，共赢 1,969/2,007 场战斗。直奔＋自动则赢了 126/200 局，74 次出局全部来自首领战，其中 70 次发生在第 3～5 层。整备路线的 81.0% 达到样本线，余量较小。调整前同口径的默认队整备＋自动为 80.5%，整备＋战术为 97.5%，直奔＋自动为 58.5%，直奔＋战术为 81.0%。地图的可达性改善可以直接验证，通关变化同时受到路线和随机战斗的影响。

ZiWu 单人于两档正面率、七组敌人的样本都落败。控制同场条件，用通用牌「断轨」打赢斥候的拼点，灰烬造成 22 点伤害，ZiWu 和 pufufu 都造成 0 点，魔理沙则因缺失 `damage_base` 报错。三者的通用牌误入专属伤害分支，东方队因此没有有效胜率。

本轮覆盖规则与地图拓扑，真人首次找路、读牌和出牌的胜率待试玩确认。

## 平衡建议

将「先用首座命运门，再在首领前到行商整备」做成新手地图上的两处提示，保留玩家自由绕路。补测中，默认队每层只主动去这两处，配合自动安排通关 185/200 局（92.5%），较直奔＋自动多赢 59 局。同一路线的战术策略通关 200/200 局。首轮真人试玩可用这条路线验证地图提示是否能帮助新手稳定过 80%。

## 第 4、5 层战前命运门复测

第 4、5 层各增加一座战前命运门，位于行商西侧一格的预留通路，每座可领取 2 点命运，可在门内升级。抽查第 4、5 层各 500 张地图，全部有三座门。第 1～3 层各两座，五层仍各有一处行商。

默认队使用同一组 200 个种子前后对照。单层首领胜率以实际进入该层首领战的局数为分母。

| 路线和指标 | 增设前 | 增设后 |
| --- | ---: | ---: |
| 直奔＋自动，第 4 层首领 | 155/180（86.1%） | 161/180（89.4%） |
| 直奔＋自动，第 5 层首领 | 126/155（81.3%） | 146/161（90.7%） |
| 直奔＋自动，五层通关 | 126/200（63.0%） | 146/200（73.0%） |
| 直奔＋战术，五层通关 | 183/200（91.5%） | 195/200（97.5%） |
| 两站路线＋自动，五层通关 | 185/200（92.5%） | 184/200（92.0%） |
| 两站路线＋战术，五层通关 | 200/200（100%） | 200/200（100%） |
| 完整整备＋自动，五层通关 | 162/200（81.0%） | 162/200（81.0%） |
| 完整整备＋战术，五层通关 | 192/200（96.0%） | 192/200（96.0%） |

新增节点对直奔路线的收益更明显。两站路线在第 5 层进首领战时，达到 100% 拼点正面率的自动安排样本从 38/188 局增至 182/186 局，整局胜率在同批样本中相差一局。

## 复跑

在项目根目录使用 Godot 4.7.2 无头运行。

```powershell
$godot = '.\.tools\godot-4.7.2\Godot_v4.7.2-stable_win64_console.exe'
& $godot --headless --path battle-demo --script 'tools/expedition_balance_audit.gd' -- maps
& $godot --headless --path battle-demo --script 'tools/expedition_balance_audit.gd' -- 200
& $godot --headless --path battle-demo --script 'tools/expedition_balance_audit.gd' -- guided default 200
```

可传入 `default`、`pufufu`、`duo` 或 `ziwu` 限定阵容，`battles` 只跑独立战斗，`runs` 只跑完整远征。地图分位数按最小值、中位数、90 分位数、最大值输出。

地图、节点、首层端到端、远征终局和命运系统共五组无头回归已通过。另跑了魔理沙与 ZiWu 的独立机制测试，用于核对现有覆盖。
