# 灰烬专属牌组试玩计划

目标：借鉴《废墟图书馆》角色牌组围绕机制协同的思路，让灰烬以准备和拼点胜利形成完整玩法。
范围：沿用硬币拼点和小队，不复制原作素材或骰子结算。新增试探、捕捉破绽、余势追击，保留观察及现有角色和通用牌；手牌横向滚动。
规则：准备最多一层，获胜获得；观察行动结束后获得；捕捉破绽在拼点开始时消耗准备，威力额外 +4；余势追击赢得拼点后追加一次 4 点攻击，目标仍存活时生效。额外数值为试玩参数。
验收：能选中四张牌、只能由灰烬使用；各效果、失败和目标退场行为符合描述；原规则及图形流程通过，并记录未验证项。

验收结果：灰烬专属牌限制、准备消耗和拼点 +4、追击胜负分支测试通过；原规则 716 项及其他角色、敌人、技能牌测试通过；图形模式自动流程通过，1440×900 截图显示 12 张牌。技能数值尚未进行玩家平衡测试；更小窗口横向滚动未人工验收。
