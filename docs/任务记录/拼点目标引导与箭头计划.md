# 拼点目标引导和箭头改进计划

目标：放大交锋箭头，区分行动格类型，并在选择牌后解释可接招和不能拼点的原因。
范围：战斗规划阶段的绘制、悬停提示与说明；不调整拼点判定、结算和数值。
方案：沿用 can_assign/can_clash 判断目标；目标校验不通过时依据公开的行动状态、目标和速度解释，其他费用等错误沿用原有校验。格子类别与可用性用不同视觉层区分。
验收：类别颜色与可用性可辨认；目标有效性和规则一致；原目标、速度相等和速度更高、未启用、防御格、cost 不足等覆盖；运行原有规则、角色和界面回归并核查截图。

## 结果与验收

已加粗箭头及箭头尖端；行动格按进攻、 大招、防御使用不同底色，目标有效性使用绿色或灰色边框。选中指向敌方的牌后，鼠标停在敌方格显示可迎击、可拦截、单方面攻击或不能安排的原因；选中的无效目标也在提示栏解释。判定复用 can_assign/can_clash，未改变战斗规则。

Godot 原战斗规则 716 项、ZiXi 47 项、东方角色 44 项、拖拽引导、地图测试与新增目标提示测试通过；图形模式原规划流程通过，1440×900 ZiXi 实际渲染检查通过。目标提示测试退出时报告 Godot ObjectDB 残留警告；未验证物理鼠标、1000×650、音效和真人对局。截图：battle-demo/test-output/target-guidance.png。
