# 仓库文档初始化计划

日期：2026-10-26
目标仓库：https://github.com/zixinyc/clash-roguelike
状态：执行中

## 目标与范围

为朋友共同开发的拼点肉鸽游戏建立公有仓库文档起点，更新 README，上传既有调研，并提供适合初次使用 GitHub 的协作指南。当前交付仅包含 README 和 docs 目录。

## 约束与方案

- 以现有仓库为准，保留项目描述；游戏引擎和具体玩法仍为待定项。
- 从公开内容中移除本机绝对路径，不上传账号凭证和游戏素材。
- 使用 GitHub 连接器写入文件，写入同一分支时依次执行。
- 本次初始化直接提交 main；日常协作建议每个任务建分支，通过 PR 合并。
- 邀请朋友、设置分支保护和选择许可证由仓库所有者后续决定，本次不代为更改。

## 执行步骤

1. 确认仓库可访问、公有、默认分支与现有 README。
2. 编写项目首页、文档导航、开发路线和 GitHub 协作指南。
3. 整理调研报告，检查相对链接与内容中的本地信息。
4. 上传文档，回读远端目录与内容验证一致性。

## 验收标准

- README 可引导朋友找到调研、路线和协作指南。
- 新手可按指南完成邀请协作者、记录任务、建分支、编辑、提交、PR 和合并。
- 正确解释公有可见性与写入权限的区别。
- 远端文件内容与本地交付一致；仅包含 README 和 docs。
- 未运行游戏、未完成的功能和未设置的仓库规则如实标明。
