# 原型架构与功能索引

按改动找一行。新阶段范围见 [AGENTS.md](../AGENTS.md)。

## 场景与状态流

- 单场 · `project.godot → battle_setup.tscn → main.tscn`。配置页交付阵容、敌组和携带牌。
- 废林 · `exploration_map.tscn → exploration_map.gd → ForestRun`。地图实例化同一 `main.tscn`，交付阵容、生命、cost、遗物和消耗品。返回地图时回写生命、cost 和道具，再由 `apply_battle_result()` 发放地图基础胜利奖励。奖励变更也要核对战斗侧遗物。
- 战斗 · `planning_ui.gd` 从 `DemoBattleRules.snapshot()` 取状态，`lock_and_resolve()` 一次产生结算事件，舞台和音效按事件播放。

## 修改时核对

- 每回合按携带牌恢复手牌。现有 `card_key` 标识牌型，队伍下标、手牌下标和行动格 ID 用于当前战斗。通用牌共享，少人补格可集中到一名成员。改打断时核对实际待结算动作与配对。
- 改牌时沿牌面和目标提示核对手动及自动规划、预留、锁定扣费、退款、角色效果和跨场景传值。改拼点时分别检查单次掷币、整场最终胜负与后续攻击掷币。
- 阶段 2 的失衡与压制由 `start()` 的可选配置启用，当前常规入口走缺省行为。废林图和节点结算由 `ForestRun` 管理，地图脚本还含旧入口兼容路径。历史设计中的地图结构或数值按源码校验。
