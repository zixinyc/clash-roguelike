# 原型架构与功能索引

更新于 2026-11-18。可玩功能以源码和对应测试为准。

## 入口与状态流

- 单场战斗 · `battle-demo/project.godot` → `battle_setup.tscn` → `battle_setup.gd`。配置页把阵容、敌组和携带牌交给 `main.tscn`。
- 废林探索 · `exploration_map.tscn` → `exploration_map.gd`。触发战斗时直接实例化 `main.tscn`，战后回写生命和 cost。
- 两个入口复用 `planning_ui.gd` 和 `battle_rules.gd`。规则通过 `snapshot()` 输出状态，`lock_and_resolve()` 生成结算事件。UI 按事件更新牌面、播放战场动画与音效。

## 源码入口

| 需求 | 实现入口 |
| --- | --- |
| 自由配队、牌的所有权和可携带牌 | `battle_setup.gd` 与规则层的 `create_roster()`、`card_owner()`、`available_cards()` |
| 敌组、牌库与回合收入 | `battle_rules.gd` 中的 `SKILLS`、`start()`、`_prepare_round()`、`next_round()` |
| 合法出牌、费用预留、规划与撤销 | `can_assign()`、`assign()`、`cancel()`、`reserved_cost()` |
| 拼点、伤害与护盾 | `lock_and_resolve()`、`_clash()`、`_solo()`、`_attack()` |
| 咲夜、灵梦、ZiXi、ZiXingYC 的专属能力 | `battle-demo/scripts/characters/` 中各自的脚本 |
| 目标引导、手牌和战斗事件演出 | `planning_ui.gd`、`role_hand.gd`、`card_view.gd`、`battle_stage.gd`、`synth_audio.gd` |

## 当前边界

单场支持自选 1～3 人、卡组和敌组。开战重置战斗状态，每回合恢复携带手牌。队伍下标用于行动和动画，技能归属按角色 ID 判断。具体试玩规则见[行动规划与速度](玩法设计/行动规划与速度.md)。

废林使用固定节点。`NODES`、`BATTLES` 定义位置，`_move()` 分发节点，`_open_node()` / `_choose()` 处理营地、事件和商店，`cleared` 防止重复领取。探险状态保存在地图场景内，地图重开或退出即重置。持久存档、正式抽弃牌堆和网络联机仍是后续范围。
