# 玩法草案编写计划

日期：2026-10-26
状态：执行中

## 目标与范围

整理当前对话已经确认的手牌、小队、拼点与 cost 经济规则，形成供朋友共同讨论的玩法草案；同步更新项目首页、文档导航和开发路线，并上传至现有 GitHub 仓库。

## 约束与关键方案

- 用户确认的方向与助手提出的测试参数分别标记。
- 不将“选择小队”扩大解释为已经确定三人、共用手牌或每人限出一张。
- cost 统一为可跨战斗保留的出牌和购物资源，区分规则选择与待验证的经济平衡。
- 当前只编写文档，不实现游戏，不宣称数值已经通过试玩。
- 保留既有调研作为历史研究资料；新增玩法草案作为当前讨论入口。

## 执行步骤

1. 阅读现有文档和远端版本，确认不会覆盖朋友的新修改。
2. 编写玩法草案，包含已确认决策、测试参数、回合候选流程、示例、风险和待定项。
3. 更新首页、导航与开发路线，避免与已确认需求冲突。
4. 检查引用和数值示例，上传并回读验证。

## 验收标准

- 明确记录小队、手牌加拼点、共用 cost 钱包、基础加表现收入、出牌限制与部分退款。
- 测试数值和待定规则不冒充用户确认事项。
- cost 收支示例计算正确，定义退款触发点并指出防刷钱要求。
- 文档导航可访问，远端与本地内容一致。
