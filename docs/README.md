## 我该把内容放哪里

- 想提新点子：写进“文档讨论”，在对应 PR 或 Issue 中交流。
- 规则已讨论确定：更新“玩法设计”，并链接相关讨论。
- 研究怎么实现：写进“技术调研”。
- 找 GitHub 操作方法：看“协作指南”。
- 查之前做过什么：看“任务记录”。

普通 Markdown 文档本身没有独立评论区；需要来回讨论时，在 [Issues](https://github.com/zixinyc/clash-roguelike/issues) 或 PR 中沟通，再把结论整理到文档。
