## 如何补充想法

先在 Issue 里写出具体场景，例如“我希望低硬币数量的技能也能靠某种效果反败为胜”，再讨论它对选择和节奏的影响。

想法确定后，将结论写入相关文档，并在 Issue 中链接到文档或 PR。尚未确定的想法标明“提议”，不要直接写成已经实现的功能。

每篇文档尽量围绕一个主题，修改时同步更新导航和关联链接。
