## 战斗特效贴图（fx/）

给拼点碰撞、命中反馈、拼点胜负这几段演出用的「一次性发光特效」。
规格统一：512×512、RGBA、透明背景、单个元素居中、四周留约 8% 余量。

| 文件 | 用在哪 | 说明 |
| --- | --- | --- |
| `fx_swipe_arc_00.png` | 挥砍时的刀光 | 白热弧线，橙边飞散，推荐主用 |
| `fx_swipe_arc_01.png` | 同上 | 更细更弯的一版 |
| `fx_swipe_arc_02.png` | 同上 | 更粗更短的一版 |
| `fx_impact_spark_00.png` | 武器相撞的火花 | 放射状橙黄火星，中心很亮 |
| `fx_impact_spark_01.png` | 同上 | 火星更细、更散的一版 |

### 怎么在 Godot 里用

这些贴图是「自己在发光」的效果，要用加色混合叠在角色和背景上，
不要用普通透明混合，否则会像贴纸一样发灰。

```gdscript
var mat := CanvasItemMaterial.new()
mat.blend_mode = CanvasItemMaterial.BLEND_MODE_ADD

var sprite := Sprite2D.new()
sprite.texture = preload("res://asset/fx/fx_swipe_arc_00.png")
sprite.material = mat
```

动画建议（配合《打击感六层拆解》里的顿帧一起用）：
- 出现：0.06 秒内透明度从 0 涨到 1，同时缩放从 0.6 放大到 1.1
- 消失：0.1 秒内透明度归零
- 位置：贴在碰撞点，刀光沿挥砍方向旋转，缩放约 0.5–0.8 倍角色体型

如果放在 `battle-demo` 里用，记得把 `asset/` 整个目录复制到 `battle-demo/` 下，
Godot 才能用 `res://asset/...` 这样的路径读到。

## 怎么重新生成

```powershell
# 1. 启动 ComfyUI（不带自定义节点更快，够用）
cd "C:\Users\ZIXIN\Downloads\aidraw\ComfyUI-aki-v3（dit，new）\ComfyUI"
..\python\python.exe -s main.py --listen 127.0.0.1 --port 8188 --disable-auto-launch --disable-all-custom-nodes

# 2. 出图
python .tools\art-gen\gen_fx.py --manifest .tools\art-gen\fx_manifest.json --batch 3

# 3. 黑底转透明 + 居中裁切
python .tools\art-gen\fx_postprocess.py <出图目录> asset\fx 512 0.06

# 4. 出预览图
python .tools\art-gen\contact_sheet.py asset\fx asset\fx\_preview_sheet.png 5 240
```

### 踩过的坑

- 贴图为什么是「黑底转透明」而不是 AI 抠图：加色混合下，贴图只要保留自己发光的颜色，
  背景纯黑且透明。用抠图模型反而会啃掉内部的暗部。
- 转透明度必须用 numpy 算。PIL 的 `Image.point()` 会把回调里的浮点结果截断成整数，
  直接写公式会得到几乎全透明的图。
- `QwenImage21Cache` 节点的 `device=auto` 在这台机器上会把十几 GB 缓存塞进内存，
  16 GB 内存扛不住，跑到第 6 张就卡死（CPU 和 GPU 都不动）。
  下次出图前先把该节点改成 `device=gpu` 或 `gpu` 放不下时改 `device=off`，
  或者把文本编码器换成 4B 版本（`qwen3vl_4b_uncensored_int8_convrot.safetensors`）。
- ComfyUI 启动时加载全部自定义节点会卡在联网检查上（十几分钟没反应）。
  出图只需要核心节点，加 `--disable-all-custom-nodes` 两分钟就能起来。
