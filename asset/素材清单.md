### 为什么不会被 Godot 导入

`参考源码/` 根目录放了一个空的 `.gdignore` 文件。
Godot 看到目录里有它就会整个跳过，不会生成 .import 和缓存。
所以把 `asset/` 整个复制到 `battle-demo/` 的时候，这堆第三方图片不会被一起导进去。

### 怎么在 Godot 里用

这些贴图是「自己在发光」的效果，要用加色混合叠在角色和背景上，
不要用普通透明混合，否则会像贴纸一样发灰。

```gdscript
var mat := CanvasItemMaterial.new()
mat.blend_mode = CanvasItemMaterial.BLEND_MODE_ADD

var sprite := Sprite2D.new()
sprite.texture = preload("res://asset/fx/fx_swipe_arc_00.png")
sprite.material = mat
```

动画建议（配合《打击感六层拆解》里的顿帧一起用）：
- 出现：0.06 秒内透明度从 0 涨到 1，同时缩放从 0.6 放大到 1.1
- 消失：0.1 秒内透明度归零
- 位置：贴在碰撞点，刀光沿挥砍方向旋转，缩放约 0.5–0.8 倍角色体型

如果放在 `battle-demo` 里用，记得把 `asset/` 整个目录复制到 `battle-demo/` 下，
Godot 才能用 `res://asset/...` 这样的路径读到。

### 怎么在 Godot 里用

WAV 会被 Godot 导入成 `AudioStreamWAV`，直接播就行：

```gdscript
var player := AudioStreamPlayer.new()
player.stream = preload("res://asset/sfx/sfx_clash_metal_a.wav")
player.volume_db = -6.0
add_child(player)
player.play()
```

要注意的两点：
- 项目现在用的是 `battle-demo/scripts/synth_audio.gd`，它是用正弦加噪声在运行时现拼的简单音色。
  这批 WAV 是同一条思路的高配版，音色层次多得多，可以整体换掉；
  也可以先只替换「拼点碰撞」和「命中」这两个最影响手感的，其余保留。
- 素材在仓库根的 `asset/` 下，`battle-demo/` 里读不到。
  要用就先把这批文件复制到 `battle-demo/` 里面（建议放 `battle-demo/audio/`），
  再用 `res://audio/...` 引用。

### 这些声音是怎么做出来的

每条音效都由几层叠成，层与层之间故意错开几毫秒，听起来才像一次真实的碰撞而不是一个单音：

- 极短的素材当「撞击瞬态」（比如 0.12 秒的金属重击）
- 长素材当「余韵共鸣」（比如 1.5 秒的金属盆、钟声）
- 层与层错开 5–25 毫秒叠放
- 变调用「时间拉伸 + 重采样」两步做，音高变了但时长不变
- 最后统一响度：按 RMS 对齐但不越过峰值上限（稀疏的硬币声就保持峰值主导）

想调手感改配方表就行：加层、改 pitch、改 gain、改 space（混响量）、改 room（混响长度秒数）。

### 踩过的坑

- 贴图为什么是「黑底转透明」而不是 AI 抠图：加色混合下，贴图只要保留自己发光的颜色，
  背景纯黑且透明。用抠图模型反而会啃掉内部的暗部。
- 转透明度必须用 numpy 算。PIL 的 `Image.point()` 会把回调里的浮点结果截断成整数，
  直接写公式会得到几乎全透明的图。
- `QwenImage21Cache` 节点的缓存设置是出图卡死的元凶，三种都实测过：
  `device=auto` 会把十几 GB 缓存塞进 16 GB 内存，跑到第 6 张就卡死（CPU 和 GPU 都不动）；
  `device=gpu` 因为显存不够，渲染会一直不返回；
  只有 `device=off` 稳定，一张 8–16 秒。
  文本编码器必须用 `qwen3vl_8b_int8_convrot.safetensors` 且 `device=default`：
  换 4B 版本会和 Qwen-Image 2.1 的采样器维度对不上直接报错，放 CPU 上编码则慢到两分钟一张。
- ComfyUI 启动时加载全部自定义节点会卡在联网检查上（十几分钟没反应）。
  出图只需要核心节点，加 `--disable-all-custom-nodes` 两分钟就能起来。
- Kenney 的下载链接要带 `Referer` 才会返回，换直链时用 `kenney.nl/download-link/<hex id>`。
- Kenney 的冲击类素材大多只有 0.1–0.2 秒，直接当成品会很单薄。
  要做出「有分量」的碰撞，得用短素材当瞬态、长素材（金属盆、钟）当余韵，错开几毫秒叠起来。
- 这台机器上 HuggingFace 不通，装不了 AI 音频/音乐模型；
  Kenney、OpenGameArt、GitHub 原始文件能访问。
