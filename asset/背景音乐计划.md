# 《余烬交锋》背景音乐计划

这份文档只讲方向和做法，还没开始做音乐。
最后附了一段可以直接粘给别的 AI 的说明。

## 一句话方向

（暗潮）暗黑奇幻打底、东方和风点色、工业废墟做肌理。
听着是"雨夜里的废站"，不是"热血战斗曲"。

## 音乐风格

### 主推：暗潮

| 维度 | 定调 |
| --- | --- |
| 调式 | D 自然小调为主，E 弗里几亚用于不安的段落。整张专辑（曲目集）不用大调 |
| 速度 | 探索 70–85 BPM；战斗 120–140 BPM，用半速双拍做出压迫感 |
| 底色 | 低音提琴 + 大提琴长音 + 合成 sub bass，负责「压着」的情绪 |
| 东方点色 | 尺八做战斗主旋（气声、断句），筝做点缀（单音，不成旋律），太鼓打重拍 |
| 废墟肌理 | 金属敲击采样、磁带底噪、偶尔一记被切断的钢琴单音 |
| 动态 | 留白多。战斗曲要有明确的「蓄力（几乎安静）→ 爆发」对比，不能从头响到尾 |
| 禁止 | 大调明亮旋律、大编制管弦爆燃、电子舞曲 drop、燃系鼓组、传统和风旋律 |

参考气质（是气质参考，不是抄）：潮湿冷硬的雨夜废墟 + 幽绿的森林 + 战斗时太鼓和尺八的宿命感。

### 备选 A：纯暗黑奇幻管弦

弦乐、低音、铜管、教堂唱诗班。人声无词，只有音高和呼吸。
不写旋律，靠和声压力推进。适合以压迫感为主的体验，缺点是东方角色会显得格格不入。

### 备选 B：纯东方幽玄

尺八、筝、环境采样。极简，大量留白，节奏慢到接近静止。
适合以叙事和探索为主的体验，缺点是战斗段落提不起劲。

三选一的话，先做主推。它能同时接住东方角色和废墟场景，备选两种都偏窄。

| 场景 | 时长 | 特征 |

## 分层（每首拆成 4 层）

Godot 里用 `AudioStreamPlayer` 分别播放各层，靠 `bus`（总线）控音量。

| 层 | 内容 | 何时进 |
| --- | --- | --- |
| A 氛围层 | pad、环境采样、底噪 | 一直在 |
| B 铺底层 | 低音提琴、sub bass | 进入场景时 |
| C 主旋层 | 尺八、旋律 | 规划阶段结束后进 |
| D 打击层 | 太鼓、金属、合唱 | 拼点命中、爆发时进 |

好处：战斗时能按回合阶段逐层加，命中瞬间加打击层，这本身就是打击感的一部分。

## 和打击感怎么配合

音乐要让位给打击音，别抢。

- 战斗 BGM 整体压到 −20 LUFS 左右，比平时低；非战斗时 −14 LUFS。
- 命中瞬间做两件事：BGM 短暂低通（0.15 秒）＋ 音量闪避（−4 dB）。这就是音乐版的顿帧。
- 太鼓的重拍和拼点回合错开半拍，避免和打击音效撞在一起。
- 顿帧那 0.08 秒里，音乐的滤波正好被拉下来，听感上像是画面被按住的一瞬间。

## 技术规格

| 项 | 要求 |
| --- | --- |
| 采样率 | 44100Hz，24bit 母带，导出 16bit 或 OGG |
| 格式 | 循环段落导出 OGG（Godot 里 OGG 更省内存），母带留 WAV |
| 循环点 | 必须精确无缝。用 DAW 的循环标记，不要靠手工裁 |
| 响度 | 统一到 −18 LUFS 左右的循环音乐；峰值不超 −1 dBTP |
| 命名 | `bgm_<场景>_<层>_<变体>.ogg`，层用 a/b/c/d |
| 交付 | 每个场景 2 个变体，随机取用避免重复 |

## 制作路径（四条，取舍不同）

| 路径 | 好处 | 代价 | 适合 |
| --- | --- | --- | --- |
| A. 下载 CC0 / CC-BY 音乐再加工 | 快，和这次音效同一套方法，授权清楚 | 风格基本要重做，改完像「处理过的素材」而不是原创 | 先垫场子 |
| B. 手工编排（MIDI + DAW） | 完全可控，能精确对上战斗节奏 | 最费时间，需要会用 DAW | 战斗曲和标题曲 |
| C. 本机程序合成（Python / MIDI 渲染） | 零依赖，可复现，能和音效共用工具链 | 质量有限，做得了 pad 和节奏，做不了有说服力的旋律 | 环境层、铺底层 |
| D. 在线 AI 音乐服务 | 出成品快，风格可调 | 需要账号和网费，产出版权条款要看清 | 备选 |

现状说明：本机没装任何 AI 音乐模型，而且 HuggingFace 在这台机器上不通，所以「本地跑 AI 音乐生成」这条路目前走不了。
音效那边能靠下载 CC0 录音解决，音乐这边同类素材质量参差、更难改出想要的东方 + 暗黑混合味。

推荐做法：A 打底拿到能用的段落，B 精修战斗曲和标题曲这两首最需要的。
C 可以顺手把环境层（pad、底噪）先做出来，这层不挑音色，也不费时间。

## 下一步（按这个顺序最省力）

1. 定风格：确认「暗潮」这个方向要不要调整（尤其速度和调式）
2. 先做 3 首：标题、探索、战斗进行。这三首覆盖 80% 的游戏时长
3. 每首按 a/b/c/d 四层出，战斗曲先只做 A 和 B 层，确认分层逻辑跑通再加 C 和 D
4. 剩下的曲目照着这个模板铺
5. 接进 Godot，做战斗命中时的音乐闪避（低通 + 音量下沉）
