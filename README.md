# Clash Roguelike｜拼点肉鸽

探索《边狱巴士》式拼点战斗与《杀戮尖塔》式卡牌构筑、随机路线和战后成长的结合，由朋友共同协作开发。
探索猎人式联机玩法！！！   还没有联机方式。。。。

**当前阶段：单机版优化中，已到可玩程度。**

## 想做出的联机体验
紧张刺激的追猎pvp模式，一个逃脱者+多个追猎者。逃脱者有先手搜寻优势，快速获取资源，快速进入下一层，找到通关方案。
追猎者有收集资源储备优势，有后手快速移动优势（当逃脱者进入某层之后，追猎者获得更多行动点）
猎人如果在pvp中，需要先确立好槽位，然后逃脱者才能应对。

## 技术方向

Godot 4 是当前调研建议，最终选择尚未确定。拟将战斗结算、动画播放和整局肉鸽流程分开，让演出加速或跳过时仍保持结算一致。

在编写完整游戏前，建议先用一场小战斗验证拼点规则和手感，再接入短路线与奖励。

## 一起协作

1. 在 [Issues](https://github.com/zixinyc/clash-roguelike/issues) 记录想法、任务或问题，一件事写一个 Issue。
2. 动手前写明认领人、改动范围和完成标准，避免两个人重复修改同一处。
3. 从最新的 `main` 创建任务分支，例如 `docs/combat-ideas`。
4. 完成后发起 Pull Request（PR，合并申请），让另一位成员检查改动后合并。

这些是团队建议，尚未通过分支保护强制执行。具体网页操作见[协作指南](docs/GitHub协作指南.md)。

## 素材与许可

参考作品用于说明玩法灵感，本项目与其开发商无关联。新增角色、美术、音乐和动画应使用原创或获得许可的素材，并记录来源。

本仓库暂未选择开源许可证。公有表示内容可被查看，不代表代码和素材可以任意商用或重新分发。引入第三方代码时，分别遵守其许可证。
