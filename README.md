# 东方异像谭 · Unity 试玩版

本分支包含五层单机探索和四层人机 PVP。普通模式从灵梦与魔理沙开始，可以挑战并招募咲夜、芙兰朵露、蕾米莉亚和帕秋莉。人机 PVP 支持自选队伍、同时选技、准备后一起拼点，并围绕异动石追猎和撤离。

- [下载 Windows 试玩版](releases/ClashRoguelike-Unity-Windows-touhou.zip)。解压后运行 `ClashRoguelike.exe`。下载整个分支的 ZIP 后也可双击根目录的 `启动Unity单机版.cmd`。
