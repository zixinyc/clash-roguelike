# 余烬交锋｜Clash Roguelike

探索《边狱巴士》式拼点战斗与《杀戮尖塔》式卡牌构筑、随机路线和战后成长的结合，由朋友共同协作开发。

本项目基于 **Godot 4.7.2 (GDScript)** 构建，支持完整的阵容配队、阳光林野随机路径探索、尖塔式卡组构筑、余烬锻台符卡附魔与多角色战术交锋。

## 🎮 下载与运行

### 方式 1：下载免安装独立运行版（推荐 · 开箱即玩）
前往 **[GitHub Releases 最新发布页](https://github.com/zixinyc/clash-roguelike/releases/latest)** 下载最新的 `ClashRoguelike_Windows_v0.4.0.zip`。  
解压后直接双击 **`余烬交锋.exe`** 即可启动游戏，无需安装任何前置环境或 Godot 引擎。

### 方式 2：使用 Godot 引擎运行源码
1. 下载并安装 [Godot 4.7.2 标准版](https://github.com/godotengine/godot-builds/releases/tag/4.7.2-stable)（无需 .NET 版）；
2. 克隆本仓库或点击 **Code → Download ZIP** 解压；
3. 打开 Godot，导入 **`battle-demo/project.godot`**；
4. 按 **F5** 运行主场景（阵容配置与探索模式选择页）。

## 🌟 核心特色与系统玩法

### 1. 废林探索与行动骰
- **1d4 行动点骰子**：每回合投掷 1d4 决定可探索步数；高疲劳（`>=6`）扣 1 步并提供 1 步保底；
- **晨曦阳光林野**：明朗通透的林野古道底图、柔和晨雾云霭、丁达尔日光束与光尘微粒；
- **探险手记与立体骰盘**：左全幅地图、右羊皮纸手记布局，16 类矢量手绘徽章，集成可点击立体 1d4 骰盘与已知地点检视卡。

### 2. 尖塔式卡组构筑与战斗循环
- **精简初始卡组**：初始牌库 10 张（4 张通用牌含断轨 + 每名出战角色 2 张专属招牌套路牌）；
- **战后 3 选 1**：战胜后从当前阵容池中 3 选 1 选卡（精英与首领提升稀有度权重），支持跳过选卡折算 +2 Cost；
- **商店符卡货架与删牌**：商店随机上架 3 张符卡，并提供 5 Cost 精简删牌服务；
- **战斗抽弃牌堆循环**：战斗内每回合抽 6 张牌，牌堆耗尽时自动洗回弃牌堆；第 1 回合内置防全防卡手保底；
- **手牌页签**：手牌区提供「本轮可用」集中展示当前角色本回合可直接打出的专属与通用手牌。

### 3. 战斗交锋与战术行动槽
- **54×48 战术行动槽**：直观展示技能简称、有效费用及单角色行动额度点；
- **三步动态高亮引导**：选牌即时呼吸点亮我方合法槽，敌方行动槽展示 `迎击` / `拦截` / `单打` / `夹击` 微标；
- **直觉快捷操作**：支持鼠标左键直接点击敌方槽安排出牌、右键一键撤销并释放预留 Cost；
- **大招格放攻击牌（Flex Attack）**：单角色可轻松在攻槽与大招槽同时安排攻击牌倾泻火力；
- **单方面攻击 / 夹击突袭**：非拼点单方面攻击与队友夹击获得 **+3 伤害加成** 与演出飘字。

### 4. 余烬锻台与符卡附魔
- **多副本稳定实例 UID**：同名多张卡牌独立绑定附魔与生命周期，删牌/整备无歧义；
- **4 Cost 符卡附魔**：锻台专属操作面板，提供轻灵（有效费用 -1 保底 1 费）与破势（拼点基础 +1）等多款符文。

## 👥 可用角色与符卡

本原型内置 8 位可选出战角色与 37 张战术符卡：
- **灰烬**（防御战士）：试探、捕捉破绽、余烬斩、守夜、坚毅守护、灰烬爆发
- **长锋**（敏捷刺客）：稳斩、破阵、残影瞬杀、疾影刺、影跃、极意斩
- **织火**（爆发法师）：护阵、援火冲击、烈焰风暴、法力涌动、炽火爆轰
- **雾雨魔理沙**（东方嘉宾）：借费机制、星屑幻想、极限火花
- **十六夜咲夜**（东方嘉宾）：飞刀投掷、时符连斩、咲夜的世界
- **博丽灵梦**（东方嘉宾）：博丽阴阳玉、封魔阵、梦想封印
- **ZiXi**（反击护盾）：蓄力轰击、破阵追击、战意昂扬、绝地反击
- **ZiXingYC**（语料解析）：认知校准、模型过载、超限收敛

## ⌨️ 常用操作与快捷键

| 操作 | 对应热键 / 鼠标行为 |
| :--- | :--- |
| **选牌** | 鼠标点击手牌区卡牌，或按数字键 **1 ～ 9** |
| **安排攻击** | 选中攻击牌后直接点击高亮敌方槽，或拖拽箭头吸附敌方槽 |
| **安排防御** | 选中防御牌后直接点击我方蓝色防守槽 |
| **撤销安排** | **鼠标右键** 点击已安排的我方槽，或按 **Delete** |
| **自动安排** | 点击下方「自动安排」，或按 **空格键 (Space)** |
| **准备交锋** | 点击居中「准备交锋」，或按 **回车键 (Enter)** |
| **演出倍速** | 顶部切换 1x / 2x / 3x 战斗回放速度 |

## 🧪 自动化测试验证

在仓库根目录使用 PowerShell 运行无头测试与图形规划烟雾测试：

```powershell
$godot = '.\.tools\godot-4.7.2\Godot_v4.7.2-stable_win64_console.exe'

# 1. 运行核心规则与探索全套测试 (25 项全量测试)
Get-ChildItem -Path battle-demo\tests\test_*.gd | ForEach-Object {
    $file = $_.Name
    if ($file -match '_render\.gd$') {
        & $godot --path battle-demo --script "tests/$file"
    } else {
        & $godot --headless --path battle-demo --script "tests/$file"
    }
}

# 2. 规划界面烟雾测试
& $godot --path battle-demo -- --planning-smoke
```
