# 主 Demo 人物整合 · 2026-11-17

## 现在如何进入

G 盘的 `启动Unity本地版.cmd` 进入同一个主 Demo，默认东方三人队。主地图顶部新增 **队伍：当前阵容 / 更换**，不用另外打开角色测试版。

可选队伍：

- 东方三人队：雾雨魔理沙、十六夜咲夜、博丽灵梦。
- ZiXi队：灰烬、ZiXi、织火。
- 原小队：灰烬、长锋、织火。

选择页列出真实角色姓名、最大生命；选择“开始新探索”才更换队伍并重置当前探索。返回按钮保留当前进度。地图设置也使用同一队伍选择入口。当前是三套预设队伍，尚未增加 Unity 自由混编或单人/双人出战。

所有队伍使用同一套森林地图、节点交互、资源、普通/精英战斗及战后结算。进入遭遇时按探索队伍创建角色和专属手牌；返回地图后继承实际生命及钱包。保留原角色，未将原角色直接改名。

## 人物与技能

| 人物 | 专属技能 | 已接入的主要状态 |
| --- | --- | --- |
| 雾雨魔理沙 | 星辰幻想、非指向性激光、天球仪、极限火花 | 火花、队伍被动、生命换敌方cost |
| 十六夜咲夜 | 杀人玩偶、特制秒表、私人空间、咲夜的世界 | 银色小刀、速度影响、私人空间、时停技能槽 |
| 博丽灵梦 | 阴阳宝玉、梦想妙珠、封魔阵、梦想天生 | 退治、封魔、梦想宝玉与延时状态结算 |
| ZiXi | 中心极限定理、几乎处处收敛、鞅、几乎必然 | 超形上学、因果律、下次拼点加成、跨回合护盾及强化 |

ZiXi强化：选中ZiXi，安排专属技能，再点“强化选中行动”。需要3层超形上学，每回合一项；撤销会释放预留层数。魔理沙等角色的具体边界沿用现有正式代码，详见 [此前技能接入说明](CHARACTER_INTEGRATION.md)。

## 本轮继承与修改

基于 G 盘已经安装的最新版本，而非早期 `unity-touhou` 开发副本。保留最新紧凑战斗、状态详情、打击反馈、速度资格，以及当前攻击硬币加值累计规则。本轮不重新调整人物数值、技能伤害、费用或回合算法。

- `Assets/Scripts/Presentation/MainDemoRoster.cs`（及.meta）：主队伍选择界面、共用启动处理、完整流程实机验收。
- `Assets/Scripts/Presentation/ForestMapView.cs`：主地图显示队伍入口，设置页复用相同选择界面。
- `Assets/Scripts/Presentation/BattleGame.cs`：接入专用验收入口。
- G盘 `Builds/Windows` 与 `Builds/ForestDemo`：更新为同一经过检查的程序集，避免备用入口仍打开旧版。
- 工作目录的东方启动文件改为指向同一个 G 盘主 Demo，旧开发工程保留供参考。

## 验证与限制

重新编译并运行八组共 **3,474** 项检查：速度/原战斗1688、直接点击28、面板25、转译131、森林135、硬币1313、东方86、新人物68。与旧轮次不同的总数来自此前本地规则更新，本轮未修改这些核心测试或角色数据。

角色外形仍为程序绘制占位，未新增正式立绘。自由混编、存档、联机、正式平衡仍未完成；角色效果的既有审核项保留。采用既有 Unity 2022.3.62f3c1 Windows Mono 播放器更新程序集，本轮不声称新的编辑器全量构建或跨设备验收。

GitHub `main` 已有独立的 Godot 阵容/卡组与少人出战设计；本轮 Unity 使用上述三套预设，未宣称两引擎完全相同。Unity 可玩整合版本继续交付到 `touhou` 分支。
