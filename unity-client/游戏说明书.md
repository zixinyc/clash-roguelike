# 《东方异像谭》游戏说明书

Windows Unity 试玩版 · 2026 年 11 月 20 日

## 一、第一次启动

打开项目中的 [ClashRoguelike.exe](Builds/Windows/ClashRoguelike.exe)，进入「出征编队」。试玩包需要完整解压，启动程序旁的 `ClashRoguelike_Data`、`MonoBleedingEdge` 和 `UnityPlayer.dll` 要放在原处。游玩 Windows 成品无需安装 Unity。

| 选项 | 玩法 | 开局角色 |
| --- | --- | --- |
| 普通探索 | 依次探索红魔馆、妖怪之山、迷途竹林、地灵殿、魔法森林。第五层找到异动石即通关。 | 初始开放博丽灵梦、雾雨魔理沙。其他普通模式角色通过红魔馆挑战解锁。 |
| PVP 人机试玩 | 你和人机轮流探索。每局从五个主题中随机选四个并打乱顺序，携带异动石撤离即可获胜。 | 可自由配置己方和人机的出战阵容。 |
| 自由演练 | 使用森林地图与探索战斗，适合试角色、卡组和混编。 | 现有角色全部开放。 |

点击左侧角色查看立绘、生命、速度、被动及专属技能。在详情中点「加入队伍」，可选 **1–3 名不同角色**。底部「左移」调整站位，「移除」腾出位置。站位会影响某些技能所说的左右顺序。PVP 顶部可切换「我的队伍」和「人机对手」，并设置两类计时。配队和战前携带符卡是两个步骤。

## 二、地图怎么走

每个地图回合自动掷一次六面骰。

| 骰子点数 | 本回合行动点 |
| --- | ---: |
| 1、2 | 1 |
| 3、4 | 2 |
| 5、6 | 3 |

- 点击高亮的相邻地点移动。两格间要有明确连接。画面上交叉的路在没有连接标记时不能换路。
- 在传送或入口上点击相应按钮，消耗 **1 行动点**下层或返回上层。你可以继续探索本层再下去。
- 深色区域尚未探索。走过的道路、可走方向、附近环境动静及队伍位置会随探索更新。隐藏捷径须先发现。
- 看右侧的资源、角色状态、行动记录和异动。足迹和噪音提供线索，敌人只有在规则允许时才显露。
- 背包中的补给、追踪工具和烟雾弹可以从资源栏使用。补给恢复存活队员，追踪工具用于侦测近处踪迹，烟雾弹用于隐藏。道具会消耗对应库存和行动点，使用前查看按钮提示。
- 行动用完或想提前交接时，点击「结束地图回合」或按 **Enter**。
- 战败会回到**当前层永远亭**，休整一个地图回合。结束休整回合后才能继续行动。

### 地点与路线

| 地点 | 进入后的处理 |
| --- | --- |
| 普通战斗、精英、异变 | 进入战斗。精英是可绕开的高收益路线，异变可能遇到较多敌人。 |
| 补给点 | 从 +3 cost 和补给道具 +1 中选一项。地点奖励领取一次。 |
| 营地 | 选择给存活队员恢复 10 HP，或获得 +5 cost。 |
| 事件和奇遇 | 可能恢复生命、获得 cost 或下一战加成。以当前地图的地点选项为准。 |
| 观察点 | 查看周边，揭示情报。首次可获追踪工具。重复观察消耗行动且不重复发工具。 |
| 隐蔽点 | 降低暴露，能刷新隐蔽，并给下一场战斗准备优势。 |
| 危险区 | 队伍掉血、警戒增加并留下噪音。首次进入能揭开附近的隐藏捷径。 |
| 行商 | 追踪工具初价 4 cost，补给初价 6 cost。同地点同一种商品每买一次涨 2 cost。 |
| 入口、传送、永远亭 | 用于跨层或同层复活。经过永远亭不会反复获得免费治疗。 |

地图上的 cost 和队员生命会带入遭遇，战斗结算后也会带回地图。准备下层时可以先看是否有营地或补给。老地图可从设定里进入，部分地点规则与多层模式有别。

## 三、普通遭遇与拼点

### 先装牌，再安排

探索战斗开战前，每名角色有 A/B 两个方案，每个方案可携带 **1–4 张专属牌**。通用牌另计。同一角色的方案会在本次游戏会话中保留。战斗中不会重新换卡组。

1. 点击己方立绘，打开该角色手牌。
2. 点击一张技能。有目标的技能会高亮可选的敌方角色或行动栏，自身技能会直接安排。
3. 点击目标，检查彩色连线。角色颜色区分行动归属，线上的「优势」「平衡」「劣势」是根据公开牌面估算的拼点风险。
4. 点「准备交锋」锁定，再点演示按钮执行。回合完成后可继续安排，战斗结束后返回地图处理结果。

探索战斗通常每人可安排两个不同分类的行动。可以指定敌方公开的行动格。速度达标或敌方原本就攻击你时，合法指定会参加拼点。同速可以接招。若多名队友都指定同一行动，最后一次有效指定获得拼点。用 **Shift＋点击敌方立绘**可找可单方面攻击的合法目标。虚线表示单方面攻击。部分专属牌需要形成拼点才能使用。

### 硬币怎么结算

- **拼点**。双方各自重新投掷全部剩余硬币。公式为基础点数＋正面枚数×拼点币值，再叠加角色和地图修正。平局重投。每次输一轮少一枚，直到一方归零。
- **攻击**。拼赢的一方按剩余硬币逐枚重投，拼输的一方此技能不攻击。单方面攻击使用该技能原有硬币。攻币值独立于拼点币值。
- **累计伤害**。普通攻击牌在同一技能内累计攻币正面，此前累计值遇到反面仍保留。例如初始 5、攻币 +2，正／反／正的逐击原始伤害为 **7、7、9**。部分注明按硬币拆分出伤的符卡有各自的结算方式。
- **结果**。护盾、减伤、角色被动与地图状态会影响实际扣血。技能前后效果与逐币详情可查战斗日志。硬币及点数跟随交锋立绘，点击角色下方状态可查看持续效果。

普通遭遇、招募战和 PVP 的战斗顶栏都可以调整动效与声音。开启动效时，拼点和命中会带动立绘、硬币与伤害数字一起震动，生命条和操作区留在固定位置。选择「动效 关」会停止震动。战斗倒计时剩余 10 秒时会变红。

| 快捷操作 | 用途 |
| --- | --- |
| Enter | 地图结束回合。探索战斗用于准备或演示。 |
| 1–5 | 在探索战斗中选当前页对应技能。 |
| Delete | 撤销当前选中的探索战斗行动。 |
| Esc | 关闭状态详情或取消当前选牌。 |
| R | 重新开始探索，会结束当前局。 |

## 四、PVP 人机试玩

1. 选择双方的队伍、地图回合时限和对战选技时限。地图默认不限时，可调 60、120、180 秒。
2. 你和人机轮流在地图行动。PVP 每层的地图布局为 **13 列 × 9 行**，只有相连的道路格可通行。两队从首层的对角出生。双方各自完成前三个地图回合后，进入正常遭遇，同层同格会打开战斗小窗。保护期间地图不会显示对方队伍。
3. 用 **10 秒**为每名己方角色携带最多 **4 张专属牌**。点「准备」或等计时结束会锁定当时的选择。空卡组仍可打通用牌。人机自行配卡。
4. 选技阶段只显示己方的「专属」和「通用」手牌。未在指定目标时，点击对手立绘可查看该角色的公开技能资料。对手实际携带的卡组和本回合选牌只会按原有战斗流程揭晓。选好角色与技能后，点击敌方立绘，或从己方立绘拖线指定目标。每名角色通常可安排一项主动行动，咲夜的时停回合开放三格。双方互相指定或符合现有速度的接招条件时会拼点。选技时限为 **20 或 30 秒**，超时会自动填补未安排的行动并锁定。
5. 安排完后点击「准备」。若人机还没准备好，会显示「对方出招中」。双方都锁定后才统一扣费、拼点和结算伤害。拼点胜者用剩余硬币攻击。人机技能随交锋和出招逐步揭晓，硬币随立绘显示。演出结束后自动开放下一回合。
6. 战胜者留在相遇点，战败者回本层永远亭。地图时限在对战中继续计时。若地图回合在对战中超时，强制结束并让两队沿合法路线后退最多两格，保留已结算状态。

### 异动石与撤离

异动石只出现在最后一层。普通探索拿到即通关。PVP 中，首次拾取异动石会恢复持有队伍的生命，开启追猎阶段和撤离出口。持有期间，战斗拼点 +1、伤害 +5。持石队在玩家对战中落败时，异动石、战斗加成和追踪标记转给胜利者。胜利者保留战后的生命值，出口留在原处。

出口在第三层或第四层生成。每队必须亲自走到相连的一格内，才会在自己的地图上标出出口。发现后会记住位置。持石队到达出口即可获胜。

PVP 的实时视野覆盖所在格和相连的一格。已探索的地方会保留路线和地点，离开后看不到留在那里的普通对手。持石者的位置持续公开，周围地形仍受迷雾遮挡。观察点和追踪工具可以记录附近路线与地点，实时视野仍维持一格。

## 五、角色与获取

普通探索初始开放灵梦和魔理沙。红魔馆有四场角色挑战，战胜后保存本机角色解锁。有空位时角色立即入队，队满时下次配队可选。若战败，当局该挑战暂时消失，开新局仍可再遇。

踏入角色地点会打开符卡战斗。可先为己方角色携带最多四张专属牌，再点「确认卡组」。进入回合后，点击己方立绘并在「专属」或「通用」里选牌，点击对手来确定攻击目标，然后点「结算回合」。挑战对手有六张符卡，每回合可出牌次数等于己方上场人数，同一张符卡可重复使用，每次分别扣费。未在指定目标时，点击对手立绘可查看这六张符卡。演出结束后自动进入下一回合。获胜后点「返回地图」即可完成招募。

| 角色 | 用法 | 普通探索获取 |
| --- | --- | --- |
| 博丽灵梦 | 以退治叠层和封魔削弱对手。梦想天生适合预先铺层。 | 初始 |
| 雾雨魔理沙 | 管理火花与 cost，用群体符卡清场。缺费时能付生命换敌方 cost。原有角色被动仍按在队成员结算。 | 初始 |
| 十六夜咲夜 | 可无视速度限制接招。银刀、秒表和「咲夜的世界」能影响行动排序，世界会在生效回合开放三格行动。 | 咲夜挑战 |
| 芙兰朵露 | 四重存在可抵挡致命伤并在回合末恢复，四层退场。攻击可留下人偶。莱万汀需蓄力后释放。 | 异常声响 |
| 蕾米莉亚 | 按实际伤害吸血并积攒绯红之主。昆古尼尔锁定带来高输出与过热，诅咒能反击，红雾能削弱对手。 | 红魔馆主厅 |

## 六、帕秋莉操作详解

- **基础**。40 HP，速度 3–5。「知识和避世的少女」闪避点数为 5。来袭攻击点数不超过 5 时闪避。「姆Q」每枚用来攻击的硬币扣自身 2 HP，治疗和降速牌不触发。
- **抽石**。「元素之石」花 1 cost。第一颗进主手，第二颗进副手。第三颗起旧副手转主手，新石进副手。拼点失败也会抽。石头在这场战斗中保留。
- **用石**。出战前携带「单元素／双元素」。获得主手后，这个栏位会变成当前可用的元素牌。相同元素可以抽到，两颗同元素不会叠加被动或派生出双元素增益。

| 元素 | 持有被动 | 主手派生符卡 | 不同副手加成 |
| --- | --- | --- | --- |
| 金 | 最终拼点 +2 | 金属疲劳，单目标、无视盾 | 攻币值 +1 |
| 火 | 最终伤害 +5 | 火神之光，容量 2，并让目标下回合燃烧 5 HP | 伤害、治疗与状态强度 ×1.5，向上取整 |
| 水 | 每回合开始回复 5 HP | 水精公主，存活队友各回 10 HP | cost −1，最低 1 |
| 木 | 攻击容量 +1 | 风精之角，敌方全体下回合速度 −2 | 可无视速度差接招 |
| 土 | 所受伤害 −5 | 慵懒三角塔，对敌全体按投出点数×目标数造成伤害 | 拼币值 +1 |

元素派生牌基础 cost 为 2。日符「皇家烈焰」花 6 cost 对全体打出 1.5 倍点数伤害。月符「寂静的月神」花 5 cost 且不拼点，使敌方接下来两回合速度减半，向上取整。「贤者之石」花 10 cost 且不拼点，召唤 15 HP、速度 1–5 的单位。从下回合起它每回合自动随机施放一张单元素牌，不额外花费，不参加拼点，可以被攻击。同时只能保有一颗存活的贤者之石。

原案未写金属疲劳硬币数，Demo 用一枚。原案只有一组币值，Demo 将基础拼币值和攻币值设成原稿同一数字，副手再分别修改。燃烧在下一回合末结算。石头与召唤物的费用及强度还需长局平衡测试。

## 七、存档、重开与试验范围

普通角色解锁会保存在当前电脑。战前 A/B 配装只随本次游戏会话保留。退出或重开不会续上地图进度。想换队时从地图设定进入「重新配队」，确认会开新局。

当前 PVP 试玩由本地人机控制第二队。旧方格地图和单场模式仍可从保留入口试玩。若使用命令行，`--grid` 进入旧网格，`--legacy` 进入旧单场。开发者可用 Unity **2022.3.62f3c1** 打开本项目的 `Assets/Scenes/Battle.unity`。
