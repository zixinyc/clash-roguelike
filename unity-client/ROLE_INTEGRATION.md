# 角色与界面成果整合

来源：`feat/touhou-characters` 的角色实现（提交 `8949db2`），以及本地最新的双方状态栏、居中交锋操作区、自动安排与动态引导。全部整合到 `touhou`；原森林小队和旧单场继续保留。

发布核对时主分支新合入 `5164446`（打击反馈），也已兼容合入：Godot 保留角色设计并合并该演出补丁；Unity 两套战斗增加蓄力、冲击停顿、受击后退、火花，音效在接触时播放。停顿仅作用于演出，不暂停规则时钟、不改变投币随机数；倍速和快速演出仍有效。

## 从哪里体验

森林地图 → 设置 / 地图 → **角色测试 · 咲夜 / 灵梦**。进入的是独立单场测试，不会修改森林小队生命、地图钱包或当前探索进度。单场顶部“阵容：东方 / 原版（重开）”可切换；切换会开始一场新战斗。

测试阵容为灰烬、十六夜咲夜、博丽灵梦。没有把原森林阵容的长锋与织火直接删除或改名。源码分支原本也将这两个角色放在测试阵容中，因此本轮沿用这个边界。

## 与新硬币规则的兼容处理

- 原角色分支的“固定总伤害”不再绕过投币。杀人玩偶每枚 5/8，阴阳宝玉每枚 3/5，梦想妙珠每枚 1/3。宝玉原固定总计 7、妙珠原固定总计 11，按新规则满正面分别为 10、15；这是规则冲突后的明确适配，需要后续平衡复核。
- 辅助牌和无伤害防御牌仍保留原有硬币，拼点胜利后逐枚完成原始判定并消耗；技能修正将直接伤害抑制为零，不触发命中、不增加护盾。不会为了“辅助”而修复或复制硬币。
- 时停提供的是三个**独立技能行动槽**。同一张牌不能重复安排，每个技能各自按固有硬币结算，不能给其中一个技能额外攻击。实机已检查一枚 + 两枚 + 两枚，共三技能五枚原硬币。
- 梦想天生爆发记为 `status_damage` 持续状态结算，单独记录，不冒充额外攻击、不增加 `attack_count` 或攻击硬币。
- 银刀和私人空间每枚攻击只各加一次原始伤害；不会通过循环反复累加到下一击。

仍需讨论：新公式下两张多币牌的平衡、追击牌新效果、是否为永不决胜配置另定规则，以及未来是否把角色测试阵容接入正式探索/养成。当前没有擅自改造地图保存格式来假装完成这些工作。

## 界面整合

继承最新的双方状态栏、居中自动安排/准备/演示区、动态引导和回合结束提示，并与新硬币面板共存。增加角色阵容切换、专属牌、定向防御选敌、时停冻结/灵活槽显示、退治/封魔标记、宝玉计数及技能详情。角色使用程序绘制的红白/银蓝占位形象；没有宣称提供正式立绘或完整角色美术。

`battle-demo` 同步角色分支的 Godot 源实现作为设计来源；本轮新硬币机制的可玩主线是 **Unity**。Godot 参考实现仍有其旧规则差异，未被当作 Unity 新规则验收，main 不修改。

## 检查与运行

新增 `TouhouRoles.cs`、`TouhouChecks.cs`、`TouhouBattleView.cs`、`TouhouSmoke.cs`，接入现有内容、战斗、状态复制、界面与编译入口。已有 3,561 项继续通过，角色新增 86 项，共 **3,647** 项。

实际播放器使用正式初始生命与费用，已验证：两组专属手牌、阵容切回原版、定向防御选择、真实时停发动、其他成员冻结、三技能五枚原币、时停到期、东方测试阵容完整战斗胜利、梦想天生实际蓄能、1440×900 与 1000×650。没有改敌我生命来制造这些结果。退治、封魔、延迟结算与死亡取消等细节另由模型测试逐项覆盖。
