# 随机关卡与战斗 UI 雏形 · 2026-11-18

## 已接入主 Demo

1. **随机地图**：默认每次新探索抽取种子，生成19～24个自然分布节点、变化的节点类型及连接；保留主线、支线、环路、汇合、隐藏付费捷径、精英与烬核/出口。地图显示种子，设置中可输入种子重建相同地图，也保留原预设和旧网格入口。保底出生、早期补给/遭遇、观察、事件、隐蔽、危险和中心地点，其余分布随机。
2. **战前技能组**：遭遇战与独立战斗都先进入准备页；每名角色分别维护A/B两套技能组，可勾选已有专属技能，至少留一张。A默认全部，B默认偏进攻；原有通用牌保留。确认不扣生命/cost，确认前180秒行动计时暂停；确认后本场锁定，排除的技能不会在下一回合重新出现，也不能通过直接安排绕过。方案在同次程序会话中跨遭遇保留，尚未写磁盘。
3. **彩色连线与风险**：青/金/紫表示三名己方角色，端点连接具体敌方行动；实线为按现有速度/最后指定规则真正配对的拼点，虚线为单方面行动。撤销和改目标会同步更新。标签显示我方技能、敌方已揭示技能或“未揭示·类别”，并以“平衡/优势/劣势”表示基础牌面预估。
4. **原立绘直接交锋**：原战场上的同一角色前冲、拼刀、后退，不弹新窗口，也不另画一组战斗替身。技能名、硬币、点数、攻击结果跟随角色横向位置；保留音效、命中停顿、刀光、倍速、快速演出和状态详情暂停。

继续使用主Demo的人物和当前战斗底层，没有恢复旧攻击规则或调整角色数值；东方三人、ZiXi及原小队入口保留。并入主项目新导入的魔理沙、咲夜、灵梦透明立绘、边缘处理和资源释放代码，原PNG字节不改动；其他角色沿用程序外形。动画为现有立绘的位置/倾斜/停顿雏形，尚非正式骨骼或逐帧动画。

## 风险提示的定义与边界

比较首轮基础牌面的预期拼点数：我方按原65%正面率、敌方按原50%正面率估算。差值绝对值不超过2标“平衡”，大于2标“优势”，小于−2标“劣势”。读取独立拼点初始值，包含ZiXi技能与攻击初始值不同的情况。

这是雏形的牌面估计，不是完整胜率；尚不计角色被动、临时状态、强化、下一轮损币及条件效果。隐藏对手时仅使用公开行动类别的通用技能范围，不读取隐藏的具体技能。提示明确标“预估”，悬停可查看点数范围和限制。后续可以接入完整状态预测，但不以预估替代实际结算。
