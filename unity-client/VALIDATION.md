# 2026-11-18 试玩版验收

本版合入斜俯视道路格、多层森林和东方角色修订。保留既有阵容切换、旧地图和战斗入口。

| 变更 | 游戏表现 |
| --- | --- |
| 单机 / 本地双队 | 5 层 / 4 层。主路、支路、回环、隐藏捷径，按显式相邻连接逐格移动。 |
| 地图机制 | 上下行设施分开。各层永远亭复活并休整一回合。迷雾、节点结算和跨层探索记录保留。 |
| 异动石 | 单机取石完成。双队取石后锁定持有者，生成第 3 或第 4 层出口，持有方满血并获得最终拼点 +1、最终伤害 +5。 |
| 配装与演出 | 每角色 A/B 方案各带 1–4 张专属技能。时停期间敌方空行动在拼点预览中安全显示。 |
| 魔理沙 | 偷取 1 Cost 扣 3 HP。极限火花在消耗前达到 5 层时穿盾。 |
| 咲夜 | 杀人玩偶正面硬币 +5，裸伤 10。 |
| 灵梦 | 速度 4–6。阴阳宝玉和梦想妙珠正面硬币 +3，封魔阵硬币 +7。梦想妙珠全正面五击裸伤为 4、7、10、13、16，合计 50。 |

编译后 **25,489 项自动检查全部通过**，其中森林规则 20,335 项。100 个种子分别验证两种模式共 900 张楼层地图，并检查复现。Windows Unity 成品实测了五层单机、四层本地双队的两种出口、跨层返回、战败复活、危险格和付费捷径、东方队战斗，以及 1440×900 和 1000×650。单机实测路线停靠了 8 个普通功能格，绕开精英通关。流程测试通过游戏界面调用的操作入口运行。Editor 全量构建受本机许可证限制。

本地双队是同机轮流操作。联网、玩家间直接战斗及跨会话存档待实现。奇遇战斗加成、遗物效果，以及龙陨石、炽热之星、咲夜误导与三槽时停、灵梦的部分技能重做待设计确认。地图经济、风险和奖励仍是待平衡数值。
