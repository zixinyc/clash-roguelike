# 正式demo角色接入 · 2026-11-17

本次基于G盘正式demo当前源码增量修改，保留地图、演出、原小队、咲夜和灵梦已有实现。

默认新探索使用“魔理沙、咲夜、灵梦”。森林设置提供“东方三人队、ZiXi独立队、原小队”三个入口；切换入口会开始新探索。单场战斗顶部可以依次切换三个阵容并重开。

ZiXi独立队为“灰烬、ZiXi、织火”，保留角色文件的owner=1，不替换东方三人队。四张专属牌在选中ZiXi后的专属技能栏显示。先安排专属牌，再点顶部“强化选中行动”，消耗3层超形上学；撤销行动或强化会返还预留层数，每回合只能保留一项强化。

魔理沙的星辰幻想、非指向性激光、天球仪、极限火花，以及火花和血量偷取敌方cost已经接入。其普通技能使用此前开发版的拼点/攻击分离数值；没有覆盖正式demo原有咲夜和灵梦数值。

ZiXi的HP、速度、费用、硬币数、拼点初始点数、独立攻击初始点数与攻击硬币点数按用户的zixi.gd录入。超形上学最多6层，每回合最多获取3层；强化消耗3层；因果律最多3层。首次反面转正只影响这一技能的一枚硬币，不增加硬币或攻击次数。

接入时对宿主代码缺失的边界采用以下约定，便于后续审核：

- 按G盘当前底层实现，后续攻击继承本次技能此前攻击硬币的累计加值；不继承拼点投掷结果。拼点和攻击仍分别投币。
- 中心极限定理强化的“攻击伤害+4”按每枚攻击硬币生效，几乎必然普通版的因果增伤同样按每击计算。
- 收敛强化的首次反面替换在整次技能的拼点与攻击间共享一次机会；只有三次攻击都是自然正面，才在第三击增加3伤害。
- 几乎必然强化胜利后的全体轰炸替代该技能普通伤害，消耗原技能的硬币预算，不额外生成攻击。
- 因果律、超形上学、下次拼点状态与临时盾是本场战斗状态；探索沿用正式demo的生命与cost继承。

这些边界需要后续结合完整宿主设计复核；本次未宣称角色平衡性已经通过。没有替换此前待审核的通用目标规则或梦想天生规则。
