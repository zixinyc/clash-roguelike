## 尚未完成

- 多人联网、正式 PVP 同图对局、匹配与同步。
- 新角色加入森林整局成长/组队系统；目前入口为地图设置中的独立“角色测试”。
- 正式角色立绘、完整动画、正式场景素材和音乐；当前角色采用程序绘制的占位外形。
- 存档、跨电脑与移动端验收、正式数值平衡。
- Unity 编辑器全量重建：本机许可仍有限制；交付使用既有 Windows Mono 播放器重新编译程序集，已实际运行，不是新的 Editor/IL2CPP 构建。
- JSON 热加载、更多具体持续效果内容、旧追加攻击技能的新效果。Godot 参考仍有旧硬币规则，未宣称两引擎规则完全一致。

## 需要重新讨论的设计

1. 原“余势追击”会额外攻击，与新规则冲突，已停用该追加效果；需决定替代效果，基础数据仍保留。
2. 咲夜固定伤害和新逐币公式的兼容、辅助技能不造成直接伤害、梦想天生作为独立状态伤害，均已明确记录，待确认最终平衡。
3. 严格规则允许永久平局配置持续重投。当前保持响应并可加速，没有擅自随机判胜；如要僵持退出需另行制定规则。
4. 先确定单机森林整局的角色编队、成长、资源节奏，再讨论多人/PVP的视野、相遇与胜负条件。
5. 旧单场与转译模式暂时并存，各自原阵容数值保留；是否统一为一个正式模式仍待决定。
